批3-a：音效（离线合成 WAV + 材质包可替换 + 三层后端）

需求：为吃/碰/杠/立直/自摸/荣和/提示等加音效，且音效也进材质包可替换范围。

方案与理由
- 素材**离线合成**：新增 tools/gen-sfx.mjs（纯 PCM 加法合成，无第三方依赖）写出
  client/assets/sfx/*.wav ×8；脚本进仓库 ⇒ 可复现、改音色不用找素材。
  tools/gen-sfx-qrc.mjs 生成 assets/sfx.qrc 兜底清单。
- 不用运行时 MIDI：Qt 没有 MIDI 合成器（Windows 上 QtMultimedia 只有 WMF/FFmpeg 后端），
  自带 SoundFont 合成器要引第三方库，破坏「客户端只依赖 Qt」这条原则。故为预渲染 PCM。
- 播放后端**按构建能力分层**（client/src/model/Sound.{h,cpp}）：
  Windows 用 winmm 的 PlaySound（系统自带、零额外体积 —— Qt Multimedia 会连带
  FFmpeg 约 20MB 与媒体插件，对绿色版不划算）；非 Windows 有 Qt6::Multimedia 时用
  QSoundEffect；都没有则静默（设置里开关置灰 + 写明原因）。三条路都编得过。
- 加载顺序与牌面同约定：材质包 sfx/ → exe 同级 sfx/ → qrc → 静音；
  Theme 新增 sfx 类别（逐文件对应，只放 pon.wav 就只换碰），
  build.ps1 把 assets/sfx 拷到 exe 同级，CMake 加 sfx.qrc 与 AUTORCC。

触发点（MainWindow::onEvent，纯客户端表现）
- meld 按 kind 分派吃/碰/杠；riichi；agari 按 from<0 分自摸/荣和；
  dora_reveal 与 ryuukyoku 用提示音；自己摸牌用最轻的 draw（别家不响）。

设置与文案
- settings.json 新增 sfx / sfx_volume（缺省 开 / 70），非法值只重置那一项；
  个人设置里加「开启音效 + 音量 + 试听」，后端不可用时置灰并说明原因。
- i18n 新增 4 条 ui.settings.sfx*，语言文件 411 → 415 条（自检计数同步）。

回归
- L2 新增 19 条断言：8 个音效都能取到 WAV、qrc 兜底存在、材质包 sfx 能覆盖且不串味、
  换回默认后仍可取到、开关/音量钳制。
- L1 559 项全绿、L2 625 项全绿。
- 踩坑记录（已写进注释与 AGENTS 9.3）：sfx.qrc 的 prefix 与条目名必须与源码里的
  :/sfx/<名字>.wav 逐字对齐，否则整条 qrc 兜底静默失效（自检有一条断言专钉）；
  CMake 条件用 #if 而非 #ifdef（"定义了但为 0"也会走 Multimedia 分支）。
