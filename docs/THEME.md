# 材质包与个人设置

面向**材质包作者**与想换素材的玩家。开发视角的取舍见 `docs/DESIGN.md`「材质包与个人设置」。

---

## 1. 个人设置（`settings.json`）

客户端会在启动时读一份设置，里面只有四项：

```jsonc
{
  "host": "127.0.0.1",   // 服务器地址
  "port": 10086,         // 服务器端口
  "name": "小明",         // 昵称（留空 = 用语言文件里的默认名）
  "pack": "D:/packs/my-theme.zip"   // 材质包：zip 或文件夹；留空 = 默认素材
}
```

- **在哪**：优先 `exe 同级/settings.json`（绿色版：解压到哪设置就在哪）；
  那里不可写时退到用户配置目录（`%APPDATA%/mahjong-client/settings.json`）。
  想临时换一份配置，设环境变量 `MAHJONG_SETTINGS=<路径>` 即可。
- **怎么改**：界面里大厅 →「个人设置」，改完点确定即写盘并立刻生效。
  另外从大厅连过一次服务器，地址/端口/昵称也会自动记下来。
- **写得坏会怎样**（这是刻意的设计，不是"容错凑合"）：
  | 情况 | 行为 |
  | --- | --- |
  | 文件不存在 | 按缺省值**生成**一份，照常启动 |
  | 文件不是合法 JSON | 原文件备份成 `settings.json.bak`，再用缺省值**重新生成** |
  | 某个键缺失/类型不对/超范围 | **只重置那一个键**，其余键原样保留 |
  | 有别的版本写的键 | **原样保留**（回写时带上，向前兼容） |
  | 文件读不出来（权限等） | 用缺省值跑这一回，**但不覆盖**你的文件 |

  也就是说：**设置文件永远不会让客户端起不来**；被改掉的键会在启动日志里列出来。

## 2. 材质包

### 2.1 支持的形式（zip 与否，结论先说）

| 形式 | 支持 | 说明 |
| --- | --- | --- |
| **文件夹** | ✅ 一定支持 | 把包解压成一个目录，设置里填那个目录 |
| **`.zip`** | ✅ 本构建支持 | 走 Qt 私有 API `QZipReader`（`QtCore/private/qzipreader_p.h`）。构建脚本检测到 `Qt6::CorePrivate` 就打开这个能力，**没有也能编**——那种构建下选 zip 会提示"这个客户端不支持 zip 材质包"并回退默认素材 |
| `.7z` / `.tar.gz` / `.rar` | ❌ 不支持 | Qt 没有这些的读取 API，也不值得为它引第三方库；请转成 zip 或直接给文件夹 |

> 结论：**主推 zip（或文件夹）**。其它归档格式需要额外第三方库，本项目坚持"客户端只依赖 Qt"，
> 所以不做。

### 2.2 目录结构

```
my-theme/                 ← 也可以是 my-theme.zip，内部结构完全一样
├─ theme.json             ← 清单（**必须是这个名字**；也认 manifest.json）
└─ assets/
   ├─ tiles/              ← 牌面 + 牌背
   │  ├─ 1m.png
   │  ├─ 5p.svg
   │  └─ back.png         ← 牌背：固定叫 back.<后缀>
   ├─ cloth/              ← 桌布（里面第一张图就是桌布，随便命名）
   │  └─ felt.jpg
   ├─ stick/              ← 立直棒（同上）
   │  └─ stick.png
   ├─ sfx/                ← 音效：**文件名固定**（见下表），只认 .wav
   │  ├─ chi.wav
   │  └─ pon.wav
   └─ font/               ← UI 字体（.ttf / .otf / .ttc，取第一个）
      └─ my-ui-font.ttf
```

### 2.3 清单 `theme.json`

键 = **可替换的类别**，值 = 该类别素材在包内的**相对文件夹路径**：

```jsonc
{
  "name": "我的牌",          // 可选，只用于在设置界面显示
  "tiles": "/assets/tiles",  // 牌面（+ 牌背 fallback）：<牌码>.svg / .png / .jpg …
  "back":  "/assets/back",   // 可选：牌背单独一个文件夹（专用目录，里面任意文件名）
  "cloth": "/assets/cloth",  // 桌布
  "stick": "/assets/stick",  // 立直棒
  "sfx":   "/assets/sfx",    // 音效：<名字>.wav（名字固定，见 2.4）
  "font":  "/assets/font"    // UI 字体
}
```

- 路径写法 `/assets/tiles` 与 `assets/tiles` **等价**（只是"从包根算起"的意思）。
- **没写的类别一律用默认素材**；写了但文件夹不存在、里面没东西、或文件坏了，
  **也只是那一类**回退默认素材 —— 其它类别照常生效。
- 路径**不能**是绝对路径（`C:/x`）或含 `..`，否则该键被忽略（这是防止材质包读到包外的文件）。
- 牌面是**逐张对应**的：包里有 `1m.png` 就只换一万，其它牌用默认素材。
  **不会**"抓一张图顶上别的牌"。

### 2.4 素材格式

| 类别 | 认的文件名 | 认的格式 |
| --- | --- | --- |
| 牌面 | `<牌码>`（`1m`…`9m`、`1p`…`9p`、`1s`…`9s`、`1z`…`7z`、赤五 `0m/0p/0s`） | `.svg`（优先）、`.png`、`.jpg/.jpeg`、`.bmp`、`.webp` |
| 牌背 | `back` | 同上 |
| 桌布 / 立直棒 | 任意（取文件夹里第一张） | 位图（`.png/.jpg/.jpeg/.bmp/.webp`） |
| **音效** | **固定 8 个名字**（见下） | `.wav`（PCM，单声道/立体声都行） |
| UI 字体 | 任意（取第一个） | `.ttf`、`.otf`、`.ttc` |

**音效的 8 个固定文件名**（与牌面一样是"逐文件对应"：只放 `pon.wav` 就只换"碰"）：

| 文件名 | 什么时候响 |
| --- | --- |
| `chi.wav` | 有人吃 |
| `pon.wav` | 有人碰 |
| `kan.wav` | 有人杠（明杠/暗杠/加杠共用） |
| `riichi.wav` | 有人立直 |
| `tsumo.wav` | 有人自摸和了 |
| `ron.wav` | 有人荣和 |
| `notify.wav` | 提示音（新宝牌 / 流局 / 设置里试听） |
| `draw.wav` | 自己摸牌（**每一巡都会响**，建议做得很轻） |

- 默认的这 8 个音效是**离线合成**出来的（`node tools/gen-sfx.mjs`，脚本在仓库里），
  所以想改音色也可以直接改脚本重跑，不必去找现成素材。
- 格式要求：**WAV**（其它格式不认，不做转码）；单文件上限 8 MB。
- 音效的开关与音量在「个人设置」里（**关掉音效时完全不读文件**，不打扰磁盘）。

- **矢量优先**：同一张牌同时放了 `.svg` 和 `.png` 时用 `.svg`（放大不糊）。
- 位图会**拉伸铺满**到该素材应有的位置与大小（作者理应给对比例，客户端不做裁切）。
  牌面的标准比例是 **3:4**（`viewBox="0 0 300 400"`）；桌布是整屏铺满。
- 赤五的牌码是 `0m/0p/0s`（不是 `5m`）：想给赤五单独做图就用 `0m.svg`。
- 单张素材上限 8 MB，清单上限 64 KB，类别目录下最多认 4096 个文件 —— 超了就当没给（回退默认）。

### 2.5 出问题时会怎样

选中的材质包只要「打得开 + `theme.json` 是 JSON 对象」就算载入成功；
之后每一类、每一张**各自**回退，设置界面里会逐条列出原因（中文），例如：

- `找不到这个材质包` / `这个路径既不是文件夹也不是 zip`
- `材质包里没有 theme.json` / `theme.json 不是合法的 JSON 对象`
- `键「tiles」的路径非法（不能是绝对路径或含 ..），已忽略`
- `键「cloth」指的文件夹在材质包里不存在，这一类用默认素材`
- `桌布文件夹里没有图片` / `桌布图读不出来（不是合法图片）`
- `字体文件夹里没有 .ttf/.otf/.ttc`
- 音效：`键「sfx」指的文件夹在材质包里不存在，这一类用默认素材` ——
  **不会**因为"包里少一个音效"就报错，缺哪个用哪个默认音效。

**设置里那条路径不会被自动清掉** —— 你把包修好，回设置里点「重新载入」就行。

## 3. 常见问题

| 现象 | 原因 |
| --- | --- |
| 换了包但画面没变 | ① 设置里那条路径没保存（看提示行有没有报错）；② 改的是另一份设置文件（看设置界面底部的路径）；③ 包里的牌码文件名写错了（例如把赤五写成 `5m.svg`） |
| 只有一部分牌变了 | 正常：牌面是逐张对应的，包里有哪几张就换哪几张 |
| 桌布/立直棒没生效 | 那两类只认位图；并且取的是文件夹里**第一张**（按文件名排序），空文件夹会提示 |
| 选了 zip 提示不支持 | 这个客户端构建没有 zip 能力（Qt 私有头缺失）；把包解压成文件夹即可 |
| 字体换了但界面字体没变 | 字体文件必须是 `.ttf/.otf/.ttc`，且取文件夹里第一个；系统里同名族可能被优先匹配 |
