## P1 ⭐ a− 的第一次强度闸门（新架构从未被测过强弱）
做什么：对手 = 既有 **3 个牌山族**（`53610001/2/3`）× 固定对手 `def7-g10` / `win2-g10` / `atk3-g10`；

为什么现在：P2–P5 全是"修结构"，而**结构修得对不对只能由强度读数回答**；没有 P1，改图的收益无法归因。
**n 的选择（先算再跑）**：① 先 **500 场 pilot**（配对、同族同对手）估 `score` 口径的配对 sd；
② `n = ceil((2.394·sd/δ)²)`，`δ` = 预注册最小效应（`score` 取 **1.0 千点**、`rank_points` 取 **1.0 顺位点**）；
③ 预算夹逼后**报实际 n 与实际 `MDE_Bonf`**（MV-1 反解参考：`score` ≈ 6,100/臂、`rank_points` ≈ 14,500/臂 ⇒ 很可能只够单口径）。
判据：**有效** = Δ>0 ∧ Bonferroni CI（z=2.394）排除 0 ∧ Δ ≥ 预注册 MDE ∧ 逐族符号一致；
**未定/测不出** = |Δ| < MDE 或 CI 含 0 ⇒ 只报"欠功率"，⛔ 不写"无效"（欠功率 ≠ 阴性）。
成本：pilot ≈ 11 min（23 场/s 量级：1,200 场 = 26 min）；**预算上限 3.5 h 墙钟**（pilot + 一次 n ≤ 7,500 场），超了停。
风险：① **跨架构不可比** —— a− vs 旧 v4 网的对打口径与历季不同（须在预注册里写明"条件于本口径"）；
② 引擎构建 —— a− 需三端 format 3 同步（R-4 已 3,083/3,083，但**改图后必须重跑**）；③ **跨族不自洽** ⇒ 族间散布要事先写进判据。
依赖：P0 的干净复现（golden 夹具）+ 三端 argmax 一致。**停止条件**：pilot 的 sd 让 n > 预算上限 ⇒ 只交"预算内 MDE"报告，不打闸门。
