## 一、项目方裁定（逐条）

- **A** = **① 特权信息只进 critic**（policy 仍**只**用公开信息）。
- **B** = 允许 **①他家手牌 ②牌山顺序（未来摸牌）③里宝** 进 critic；先训**独立小网 privileged critic**，
  **推理不用 critic**，训练期把 critic **内化（蒸馏）到主网的 value 头**。
  ⚠ 内化判据三条：① 特权输入置 0 ⇒ **policy 逐位不变**；② 主网 value 与特权 critic 的秩相关/EV 达标；
  ③ 主网 value 必须**胜过"纯公开信息"的价值基线**。
- **C** = **4 h 配额含自对弈采集**，按"上次训练时间"反推轮次（⚠ 与旧文档"4 h = 纯训练墙钟"不同，以本条为准）。
- **D** = **不是单轮长训**：切成**多轮**，且**显著减少评测次数**（短评测分辨率不足且浪费时间）。
- **E** = **只报整体结果、不做归因**。
- **F** = **弱监控**（C8-v2 的 `KL/100step`、`top1` 比、`frac(u==0)`、`tile_id max|emb|`），**不自动停**。
- **G** = 训练对手组成 **≥50% 行外/历史网**（本族 ≤50%）；验收必须报"**对行外池的增益**"。
- **H** = **弃用 v4 架构**（不再训练 / 不追求），但 **v4 冻结网仍可作对手池**
  （`def7/win2/atk3-g10` / `defrep-g10` 可用）—— ⚠ **弃用架构 ≠ 弃用旧网作对手**。
- **I** = **失败出口**：本轮任务结束时做**静态汇总 + 轻度反思**，然后**停下等项目方**
  （⛔ 不许自行继续开新实验）。
- **J** = 文献已由父代理汇报并采信：PerfectDou（arXiv 2203.12035）/ PTIE 支持"特权只进 critic"；
  PTIE 的 privileged→public 蒸馏支持内化；**但本仓自有实测：加宽/加深 critic 读出头无效、PBRS 无效**
  ⇒ 内化只能走**蒸馏 / 校准**，⛔ 不要再试"加宽读出头"。
