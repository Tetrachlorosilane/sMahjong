## 2 被测指标（逐字定义，与第九十一/九十七轮同一套方法，⛔ 不新造）
- `KL(π_trained‖π_init) = mean_{学生行} Σ_c π_t[c]·(log π_t[c] − log π_i[c])`（nats）。
- 学生行 = 紧凑集 `E:\mahjong-training\compact\ov-A-s00` 的 `val.is_student` 行（**8,397 / 33,615**）。
- 口径：**纯推理复算**——`tools\v4-forward-gpu.py --rows <该目录> --split val --format jsonl` 各 net 一份 33,615 行，再用第九十七轮 `kl_measure.py` 的同一公式（⛔ 不用训练日志里的 `ref_kl`，那是 π_ref 口径）。
- **两个温度都报**：`T=1.0` 与 `T=0.5`（同一份 logits，`softmax(logits/T)`；T=0.5 只换温度，⛔ 不改行集）。
- 同时报 **argmax 翻转率**（init vs trained、同一 `argmax` 字段）。

## 3 点位设计（**一次只动一个旋钮**；全部带 `--cache-ref-logits .tmp\mv1-s98\refcache`）
底盘（第九十七轮 base 臂逐字配方，含 `--init`=`--behaviour`=`tools\build\v4-expert-defrep-g10\net.bin`、`--batch 512 --head-lr-mult 3.0 --seed 20260927 --stage-a 0 --stage-b 0 --ref-beta 0.1 --grad-clip 0.5 --kl-early-stop 1 --kl-min-steps 100 --threads 8 --objective ppo --behaviour-temp 0.5 --value-target delta --advantage hand --rank-weight 0.2 --baseline-fit scale`）。
- **A 步数轴**（`--lr 1e-3`、`--epochs` 固定 12）：`--max-steps` = **50 / 100 / 200 / 400** ⇒ 总步数 **600 / 1,200 / 2,400 / 4,800**。唯一自变量 = 总步数（⚠ 副作用照实记：本配方的余弦只覆盖 `total_steps`，故长跑的余弦地平线同时变长——这是"加步数"在该配方下的固有含义，不额外算作第二旋钮）。
- **B lr 轴**：步数取 A 中**离 0.1 最近**的点（该点 `lr=1e-3` 已在 A 里 ⇒ B 只新跑 **3e-3 / 1e-2** 两档）。⚠ 1e-2 若发散/NaN ⇒ 如实报并**停止该轴**。
- **C 覆盖轴（可选）**：**600 步固定**，`--batch` = **256 / 1024**（512 = A 的 P600 点，复用），看覆盖的边际效应；跑前过 R-2 准入（batch 1024 峰值按 2× 报）。
- **预声明的墙钟规则**：每点 ≤5 min 是**目标**；按第九十七轮实测 `0.211 s/步`（含 12 次 val）⇒ **2,400/4,800 点必然超**（≈8.4/16.9 min）。处置（跑前定，⛔ 不是事后改口）：① 仍按 A 轴跑；② 全程**一次一个重负载**；③ 若剩余墙钟不足，**从最高点开始丢**并在报告中标注 dropped；④ C 轴仅在 A+B 之后仍剩 ≥8 min 时跑。

## 4 判据（每点必给）

## 6 跑后偏离（只追加；⛔ 不改 §1–§5 一个字）

- **D-1 环境（不是设计）**：子进程沙箱不允许写工作区外路径（`S:\` 的 `.write-probe` 被拒 ⇒ `DataRootError`）⇒ 用 `MAHJONG_DATA_ROOT=.tmp\mv1-s98\data-root` 把 **ckpt 根**改到仓库内 gitignored 临时根。**训练数学零影响**（`--data`/`--init` 仍指原位；ckpt 路径不进 `net.bin`、不进 `_state_sha256`）。自证：P600 的 `net.bin` sha256 = `16846C25…0FCB`，与第九十七轮 base 臂**逐字节相同**。
- **D-2 B 轴步数**：A 轴四点 KL 全部落在 0.0165–0.0180（极平）⇒ "离 0.1 最近"无判别力；取 **1,200 步**（4,800 步跑 B 两档需 ~22 min，超 90 min 预算）。此为预声明墙钟规则的执行，非事后挑点。
- **D-3 追加确认点 `T6e3`（跑前声明，一次性，⛔ 不扫描）**：`lr=6e-3 / 1,200 步`。理由 = B 轴两点给 `KL ∝ lr^0.90` ⇒ 外推 0.1 需 lr≈7.3e-3，而 1e-2 已发散 ⇒ 必须在 (3e-3, 1e-2) 内确认一次。判据（**跑前**）：① `stop_reason` 非空（KL 早停/NaN）⇒ 判"该档也发散"，外推作废；② 跑通且 `KL(T=1.0) ≥ 0.1` ∧ 学生行 top1 ≥ 0.8×init(0.5631) ⇒ **最小配方成立**；③ `KL ∈ [0.06,0.1)` ⇒ 判"外推不成立、6e-3 仍不够"。
- **D-4 事故**：`L1e2` 首次起跑在 `log π_old` 分配相 **0xC0000005**（8.2 s，未进任何一步）；同命令重跑即过（第八十七轮同类机器级偶发）⇒ 记为偶发，不当作 lr 效应。
