## 1 三个估计器（同一个量：Δ = 候选 − 基线 的学生席配对差）
- **O0 现状**：`Δ̄ = mean(d)`、`SE = sd(d)/√N`（N = **场**数、跨族池化）—— **就是闸门现有口径**：
  本工具重算与既有 `verdict.json` 逐位同（s35 **−2.1617 / SE 0.8513**、s38 **+0.9307 / SE 0.8324**）。
- **O1 同山配对 + 按场聚类**：簇 = 牌山(seed)，`v̂ = G/(G−1)·Σ_g S_g²/N²`（`S_g` = 簇内**残差**和；分母 `N²`，不是 `G²`）。
  本设计**每簇只有 1 个学生席观测** ⇒ 代数上 `v̂ = sd(d)²/N`，与 O0 **恒等**（实测比 **1.000000000**）。
  ⚠ 真正的坑不是"少算聚类"，而是**把四席 / 24 排列当独立样本**：`--seats4` 实测 4N 行 ⇒ `Δ ≡ −1.1e−16`
  （零和恒等式；`max|Σ四席| ≤ 1.8e−14`）、朴素 SE **0.4317**（假精度）、按场 CRVE **3.6e−17**（退化）⇒ 这条路**零信号**。
- **O2 CUPED**：`X` = **基线臂在同一副牌山、同一个座位上的结果**（同山天然协变量）；`β = Cov(d,X)/Var(X)`、
  `θ = Δ̄ − β(X̄ − X̄_∅)`；**K=10 折交叉拟合**（β 与参照均值只用其余折、SE 只用**折外**残差；族内位置 `%K` 定折）。
  闭式：`VR = ρ(d,X)²`、`SE↓ = 1 − √(1−VR)`；`σ_Y≈σ_X` 时 `VR = (1−ρ_YX)/2`。

## 3 负向对照与"作弊"边界（⚠ 必须有）
- **置换协变量**（同山对应关系打乱，300 次）：VR 均值 **−0.023% … −0.074%**、95% 分位 ±0.1% ⇒ **收益 ≈ 0** ✔（估计器没自造增益）。
- **错误示范 ①**（z = **Δ 本身**，即"候选自己的结果 − 基线"）：SE **4.8e−3 / 3.8e−3**（= O0 的 0.5%，**SE↓ 99.4–99.6%**）、Δ 不变 ⇒
  判据 **被循环协变量骗过**；**错误示范 ②**（z = 候选臂自己的结果，post-treatment）SE↓ **21.1–21.5%**——与合法同山协变量**对称**
  ⇒ **"收益大小"本身分不出合法/作弊，边界只能靠"可得时机"**：协变量必须是**判决前可得、且不受候选臂影响**（同山基线臂 ✔ / 候选自己 ✘ / 终局信息 ✘）。
- 与判据 22①（特权只进 critic）**无关**（那是训练期口径）；但 D2 批注要求"评估期用特权协变量需项目方裁定"⇒ **本批只用公开/同山协变量**。

## 4 判据（冻写后跑）：**不通过 ⇒ 不集成**
- 冻写：`O2 相对 O0 的 SE 降低 ≥25%`（等效 n ≥1.78×）**且** 点估计漂移 ≤1 个 SE_O0。
- 实测：SE↓ **19.15 / 20.36 / 21.09 / 21.42 / 20.80%**（4 批 + score 口径，全部同向同量级）⇒ **差 ~4pp 不过**；漂移 ≤0.023 SE ✔。
- **为什么过不去（闭式）**：`VR = ρ(d,X)²`，要 SE↓≥25% 需 `|ρ(d,X)| ≥ 0.661`；本数据 `ρ(d,X) = −0.589…−0.619`。
  又 `σ_Y≈σ_X` 时 `ρ(d,X)² = (1−ρ_YX)/2` ⇒ **判据 ⟺ ρ_YX ≤ 0.125**（"配对几乎无效"）。实测 ρ_YX = 0.24–0.28
  ⇒ **只要配对仍然有效，把"配对伙伴"当协变量就结构上到不了 25%**（配对 ≈ 已把 CUPED 的 β=1 那部分收走）。
- 后果（若强行集成）：s38-formal 的 MDE **2.332 → 1.857 ≤ δ=2.0**、CI [−0.375,+2.224] —— 分辨率够、**判决仍然"测不出"**（CI 含 0）⇒ 只值得记账。

## 5 rliable / IQM 判断：**本判据下不用**
- IQM（两端各裁 25%）实测 SE 比 **0.976 / 1.014 / 1.022 / 1.002 / 1.026×O0**（等效 n **0.97–1.00×**）⇒ **零增益**（顺位点有界、不重尾，裁掉一半样本只换来更粗）。
- 且 rliable 的分层 bootstrap 要 **≥5–10 个 run**，我们只有 **3 个牌山族 = 3 个 run**（族间 χ² 只 2 自由度；本工具实测"族当簇"比值在 **0.20–0.65** 之间乱跳，两个方向都不可靠）⇒ **IQM/分层 bootstrap 不可估**，⛔ 不用。

## 6 结论与集成决定
- **不集成** `--cuped`：判据未通过（20–21% < 25%）。`tools/ceiling-gate.py` 的 `--cuped-report` 是**报告档**
  （缺省关；打开只写 `estimator.cuped_report`，判决仍 O0）—— 这是"仅报告"，⛔ 不是集成。
- 若项目方日后另开判据（如"≥20% 且 MDE≤δ"或"报告档、不改判决"）再考虑：形态 = `--cuped {off|samewall}`（缺省 `off`）+ 输出**同时**报 O0 与 O2 两套 Δ/CI/MDE + `verdict.json` 加 `estimator` 字段；
  ⛔ 三条缺一不可：① 判决口径不变（仍 O0）；② 协变量缺失/常数 ⇒ **fail-closed（退出码 2）**，⛔ 不静默退回 O0；③ O0 段逐字节比对 600 场同命令。
- **对文献批注的更正（Q2）**：`sd 55.95` 是 **σ_Δ（配对差）**、不是 σ（单臂 45.3）⇒ 由它反推的 ρ≈0.64 **偏高**，真 ρ_YX = 0.24–0.28；
  "配对+CUPED ≈2× 等效分辨率"**方向成立**（实测 2.07–2.24×），但**归因要改**：大头是配对（1.31–1.38×），CUPED 增量只有 1.53–1.62×。
- 局限：**条件于 `53610001/2/3` 三族**、只 rank/score 两个指标、⛔ 不跨族外推；⛔ 未新增任何场次（全部既有证据）。

## 7 项目方裁定（2026-10-20）：CUPED **仅报告、不进判决**
- 原话「**CUPED 不进闸门，仅报告，进行下一步**」。落地 = `tools/ceiling-gate.py --cuped-report`（**缺省关**；
  打开只在 `verdict.json` 写 `estimator.cuped_report`，**判决仍用 O0、⛔ 不改 PASS/FAIL/退出码**）；协变量 =
  基线臂同山同席结果，缺失/常数 ⇒ 该字段 `null` + 警告。
- **理由**：① 判据（SE↓≥25%）在 `VR=(1−ρ_YX)/2` 闭式下等价于 `ρ_YX≤0.125`，本数据实测 **0.24–0.28** ⇒
  **结构性不可达**；② 提高分辨率**不会凭空造出效应** —— s38-formal 即使 CUPED 把 MDE 压到 1.857≤δ=2.0，
  CI 仍含 0 ⇒ 判决仍是"测不出"；③ 因此只值得记账，不能进闸门。
