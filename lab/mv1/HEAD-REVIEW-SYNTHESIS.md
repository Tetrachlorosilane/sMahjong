## 2 被 A1→A3 推翻/修正的两条

1. **"该删 `danger`"（两家一致）→ 实测可学，不删。** A1 诊断把"0.47–0.53 ≈ 先验"归因到**读数口径**：
   标签是**小局级广播**、而旧读数在 P 口径（全行）上量；改到 S2 行集（每 `(场,小局,座)` 最后一条决策，
   12,933 行 × 3 家）后 plain BCE OOF **AUC 0.8711 / PR 0.3336 / Brier 0.0586 < 0.0708**，
   同宽对照 +0.0095 / 随机 +0.3342 / 打乱 +0.3882（噪声地板 ±0.0013）⇒ **信号在输入，不在"头没救"**。
   ⚠ 但 A3 comparator ρ **−0.171** ⇒ **不能当便宜进度计**（两家都没主张这一点，是本轮新增否定）。
2. **"BCE 11.9 与 AUC 0.83 不可能共存 ⇒ 至少一处量纲/归一化错"（Gemini §2.2）→ 不是 bug，是过置信，Platt 可修。**
   同一个头、同一批 val（n=14,831）：校准前 BCE **13.46/13.03/13.18**、AUC **0.875/0.849/0.800**；
   Platt `a·bt+b`（a=0.191/0.229/0.207，b=−8.00/−7.40/−7.31）后 BCE **0.304/0.330/0.374**（2 折 OOF 0.308/0.336/0.378，
   与 A1b 逐位一致），**AUC 保持**（差 ≤1.5e-8）⇒ "饱和"是**偏置**（缺截距），不是损失/席序错；
   温度单独无效（T 顶到 2000 仍 BCE 0.697）也印证"缺的是截距"。

## 3 四条修正（细节/数值见 `lab/mv1/HEAD-DESIGN-FIXES.md`）

1. `belief_tenpai` 的 Platt `(a,b)` **烘进最后一个 Linear**（`W←a⊙W, c←a⊙c+b`）：形状/参数/`net.bin` 布局不变。
2. 门控输入 **`sigmoid(bt).detach()`**（`--belief-gate-detach`）：只断 policy→belief 这一路，belief 自己的 BCE 照常。
3. a− 的 `danger` logits 项改**有界**：`DANGER_COEF·(mean_k σ(d) − 逐行均值) ∈ [−1,1]`（`--danger-form bounded`）。
4. `ONLINE_HEADS` **按 arch 分开**（a− 补 `danger`；三端字面量 = 并集）。

## 4 剩余分歧（本轮不裁定）

- **`belief_tenpai` 该不该留在 policy 路径**：Gemini 要求"修好后 KL≥0.02 才保留"，Luna 主张"先删 gate 当诊断"；
  本轮只做"能修"（校准+detach），**没有**重跑 gate 清零探针 ⇒ ⛔ 不下"保留/移除"的结论。
- **`danger` 标签**：两家都要求逐决策可归因（本行打出的牌被荣和）；A1 证明**现有广播标签**也能学到 0.87，
  但那是**状态级**危险度，⛔ 不能当候选级解释。改标签要重采 ≥200 场，本轮未做。
- **`value`/`placement`/`belief_hand` 的取舍**：Gemini 要删 placement/belief_hand，Luna 要合并 value/placement；
  本轮只把权重降到 0（`--head-loss-weights`，命令级、不改注册默认），张量与 `net.bin` 一个字节没动。
- **"辅助梯度 1.6× 主项"**：两家算术不同（注册表 Σ(non-policy)=**1.8**；去掉 value 0.5 = **1.3**）。
  本轮按"**显式逐项 ≤0.8**"给表（见 fixes §6），⛔ 不再引用一个含糊的 Σ。
