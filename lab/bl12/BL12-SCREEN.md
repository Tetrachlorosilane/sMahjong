## 2 探针（问什么 · 怎么判 · 与旧探针的区别）

- **P1（主）**：给定决策行 i 的**合法公开状态**，预测**随机一席对手当前是否听牌**（标签 = 冻结件 `aux_opp_tenpai[i,j]`，引擎真值、训练期标签；正比 0.1319）。**P2（次）**：同状态 → **同手未来 8 行内是否出现立直事件**（标签从 `evt` 窗口扫 `riichi` 派生，**公开可算、零隐藏量**；正比 0.3777）。
- **学习器两端严格等算力**：同架构（tile 线性 + evt GRU + ctx 线性 + 同 head）/同 seed/同 epoch 上限/同早停，只差候选块（只进 head 首层宽度）。读数 = **样本外 AUC**（按**手** 5 折 GroupKFold，同一手只进一折）+ **按场聚类** bootstrap 95%CI；配对 Δ 用同一次重采样的配对 bootstrap。**判据（跑前写死）**：`in 强` = AUC>0.5 ∧ 配对 Δ 的 CI 下界>0 ∧ Δ ≥ 实测 MDE ∧ Δ > 最强安慰剂增益；`in 弱` = AUC>0.5 但不满足上式；`出局` = AUC ≤ 0.5。预注册 **MDE=0.020**，同时上报实测 MDE_paired。
- **⚠ 与旧探针的区别（逐条）**：① **问题**：旧问"同一状态下**哪个动作更好**"（反事实、要动作配对），本问"公开状态能否预测一个**公开结果**"（无动作、无配对）；② **标签**：旧 = 净得失 Δ（结果量、含隐藏量口径、要 oracle 增益），本 = 听牌/未来立直（**状态量/公开事件**，✗ Δ、✗ 神谕）；③ **口径**：旧按"同状态配对行"造样本，本按**决策行**（同手只进一折）；④ **为何不再犯**：旧失败模式（ρ(Δ,基准)=−0.694 的均值回归 + 低于最强安慰剂）在本设计里**结构上不存在**（没有 Δ、没有基准臂）。

## 4 结论（BL-12 的第一步）

1. **可证伪性成立**：C4 按跑前判据**真的出局**（Δ=−0.0022，AUC 0.9041 < base 0.9063）；判据没放水（若全 in 就要复核，本批没有）。**观测侧在这两个公开结果上"接近饱和"**：base 用现有 v4 观测就到 **AUC 0.906/0.879**；四条新候选增量全部 ≤ **0.0043**，只有 C1 刚好越过实测 MDE ⇒ **没有一条够格开训练臂**。
2. **"信念回灌"（规范明确排除的那一招）Δ=+0.0015（CI 含 0）** ⇒ 与本批其余候选同量级，⛔ **不构成"解锁 0.0693 天花板"的证据**（本探针问的是"公开结果可预测性"，不是价值目标可学性）。**建议**：观测侧不再加"逐席聚合"这一族（已含或冗余）；BL-12 要继续走就优先**目标侧**（§1 那三条，尤其"自家手牌价值"——它有一条**从不进输入**的独立信号，本批未测）。
