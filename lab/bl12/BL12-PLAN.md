## 3. 探针定义（问的是什么）

- **P1（主）**：给定决策行 i 的**合法公开状态**，预测**随机选定的一个对手席 j 当前是否听牌**
  （标签 = 冻结件 `aux_opp_tenpai[i, j]`，引擎真值，**训练期标签**）。正比 ≈ 0.13。
- **P2（次）**：给定同状态，预测**同一手未来 H=8 行内是否出现立直事件**（标签从 `evt` 窗口逐行扫
  `type==riichi` 派生，**公开可算、不需要任何隐藏量**）。
- **与旧探针的区别**：旧探针问"**同一状态下哪个动作更好**"（反事实配对，标签 = 净得失 Δ，含隐藏量口径），
  已判负（AUC 0.4799 CI 含 0.5、低于最强安慰剂 0.0491、ρ=−0.694 ⇒ 方向族封存）。
  本探针问"**公开状态能否预测一个公开/训练期标签的结果**"：不构造反事实、不比较动作、标签不做差分。

## 4. 判据（跑前写死）

学习器两端**严格等算力**（同架构/同 seed/同 epoch 上限/同早停；只差候选块，`dim` 只进 head 首层宽度）。
主读数 = **样本外 AUC**（按**手**分 5 折 GroupKFold，同一手只进一折）· 95%CI = **按场聚类** bootstrap。

- 预注册 **MDE 声明 = 绝对 AUC 增益 0.020**；同时**实测上报** MDE_paired = 2.802 × SE_boot(配对差)
  （口径同 `mahjong_ml/eval.required_n` 的 2.802 = z_{0.975}+z_{0.80}）；**若实测 MDE > 声明值，以实测值为准**
  并在判决里注明"该 N 下分辨率不足"。
- **判决**：`in 强` = AUC>0.5 ∧ 配对 Δ 的 CI 下界>0 ∧ Δ ≥ 实测 MDE ∧ 增益 > 最强安慰剂；
  `in 弱` = AUC>0.5 ∧ 增益 ≤ 最强安慰剂；`出局` = **AUC ≤ 最强安慰剂**。
- **安慰剂三项**（同一学习器/同一折/同一预算）：① 按**手内打乱标签** ② **非目标席**（换成下一席）标签
  ③ **只用动作键**（`tile`/`evt` 置 0、`ctx` 只留 `round+ask`）。另报 `random=0.5`。
- **可证伪性（什么算失败）**：任一候选 AUC ≤ 最强安慰剂 ⇒ **出局**；若**全部候选 in** ⇒ 判据太松，必须复核
  （本批已预置一个**预期出局**的对照：C4 = `ctx` 的确定性线性重编码 ⇒ 对 MLP 是纯冗余，预期 Δ≈0）。
