# 预注册：`fold` 轴（**被威胁时的降り率** · 弱口径 = 現物）· 1 链 × 1 代 · 逐行同权点剂量

## 1. 轴定义（只用公开信息）

- **被威胁（T1）**：该行 `obs.riichi[这一行的行动者]` 为真 ⇒ **至少一家处于立直状态**（立直宣言已发生；`obs` 只在**询问那一刻**构造 ⇒ 出现该状态就意味着这一小局**还没结束、威胁仍活着**，⛔ 不另做"和了/被鸣"的重建）。
- **付奖行（唯一口径）** = **出牌行**（`chosen` 以 `discard:` 开头）∧ **被威胁** ∧ 打出的牌对**每一个**威胁家都是 **現物**。
- **現物（弱口径安全牌）** = 只用 `obs.events`：该家 `type=="riichi"` 那条事件**之后**的 `discard` 牌 **＋ 宣言牌本身**（`discard.sideways`，麻将标准口径"进过河不与荣"）。⛔ 不用别家手牌 / 牌山 / 里宝 / 别家听牌；也**不用**引擎 `Danger`（它不在 `obs` 里）。
- **方向（单向）**：只对"切了安全牌"付奖，**押し（不安全）那一侧一分钱不付**。**选 `fold`（降り率 ↑）的理由**：① 普查的判别力来自**放铳**（`deal` 押 28.7% vs 降 21.0%）⇒ 降り这条行为**直接对应"少点炮"**；② 推 `push`（"被威胁时别缩"）在**弱口径**下等于推"切非現物"，那是把"多切危险牌"当目标，与 `no_deal` 质量轴自相矛盾（会大面积拦下）。
- **伴随质量轴** = `no_deal`（该小局未放铳）。⛔ **不是恒真**：切了現物**照样可能放铳**（自摸 / 被别家荣和 / 自己之后点炮）⇒ 闸门 `ROW_PAIR_MUST_BLOCK` 要求实测 `blocked_rows > 0`。
- **手级指示量** = 该席本小局**至少有一行**是付奖行（与行级**同一把尺子**，只服务"手级=1 ⇔ 有动作行"这条结构不变量）。
- ⛔ **威胁集本轮不扩**（只 T1）。T2/T3 的规模由数据另表测量（见 §5），**不进本轮的轴**。

## 2. 最终形态付奖行率门槛（**训练前**判）

- 判据：**付奖行数 ÷ 学生席决策行数**；**< 1%/行 ⇒ 立刻中止（不跑训练）**，报告"未过门槛 + 为什么 + 建议的替代定义"。⚠ 这正是 `riichi_turn` 踩过的坑（未加阈值 1.91% → 加阈值后 0.79%）。
- 实施：先用审计账（compact 建列阶段打印 `action_rows / paid_rows / blocked_rows`）在**最终形态**上读这个率，再看 §3 的链。

## 3. 链 / 主判据 / 伴随量 / 止损

- 配方：`--style-bonus 'fold=W:no_deal'` + `--style-bonus-mode decision`、**1 链 × 1 代 × 1000 场**、`-NoGate`；链 `v4-wl-fold-c1-c1`（seed **24620091** / 采集 `seed_base` **24620092**，与历次各族 24310011..32 / 24310041 / 24310091-92 / 24620011 / 24620021 / 24620051-52 / 24620061-62 / 24620071-72 / 24620081-82 / 闸门 40970001-4 **都不相交**）。
- **剂量**（逐行同权点 = 比值 `1/√2`，按 `parity_note` 的逐行读数校准）：`k = √(q(1−q)·(1−μ)/μ)`，`q = P(no_deal|付奖行)`、`μ = 付奖行率`；逐行白化后 `std(塑形列) ≈ w` ⇒ 取 `w* / k` 与 meld/rt 轮实测的 `δ = 5062.6/5191.4 ∈ [0.975,0.976]` 反解（实测见报告 §5；⛔ 不为做大效应上调）。
- **主判据**：`post` 补采（末代权重、**同 seed 逐场配对**，自证 seed/学生席不一致 = 0）的**行级** `fold_rate`（= 付奖行 / 被威胁行）配对 Δ + 95% CI；**方向为升** ⇒ Δ 为正且 CI 排除 0。辅 = 每场每席付奖行数 + 聚合 `fold_rate`。
- **对账（硬）**：`fold_rows`（判据侧独立实现）== 审计账 `fold_rows` == `action_rows`；`threat == fold + push + missing`；`paid + blocked == action_rows`。
- **伴随量（六个，护栏单侧）**：放铳率 / 和了率 / 立直率 / 副露率 / 打点（`avg_win_score`）/ 立直后和了率（`riichi_win_rate`）+ `quality`（越界 ⇔ **CI 上界 < 0** 或 **点估计 < −tol**）。
- **止损**：任一伴随量越界，或 `deals` 同量纲 Δ ≥ +0.10/场/席 ⇒ **立即结案**，⛔ **不事后改判据**。

## 4. 预先写明：三种结果各自意味着什么

- **没位移（CI 含 0）**：付奖行率≈1.1%/行（刚过门槛）⇒ 与 `riichi_turn`（0.79%）同类的信噪比问题：结论是"**这个弱口径的降り在 1 代 × 1000 场下测不动**"，下一步换**威胁/安全口径**（T1∪T2、或"对至少一家安全"），⛔ 不是加剂量。
- **方向反了（Δ 为负且 CI 排除 0）**：这笔钱在推**押し** —— 最可能是"付奖行与伴随量不同源"导致的反向信用分配 ⇒ 判该轴（该口径）不适合行级正推，改当判据侧读数。
- **方向对但代价太大（任一伴随量越界）**：按 §3 止损结案，写清"降り可以被推上去、代价是什么"。

### 6.2 偏离记录：§1「被威胁」的措辞与实际付出去的口径

- §1 写的是"该行 `obs.riichi[**这一行的行动者**]` 为真 ⇒ 至少一家处于立直状态"。
  **这句措辞是歧义的**（`obs.riichi[actor]` 为真 = **行动者自己**在立直，不是"别家"）。
- **实际付出去的口径（冻结审计账 `audit/v4-wl-fold-c1-g01.json` 实测）**：按**字面**执行 ——
  威胁集 = 当行 `obs.riichi` 里**所有**为真的座位（**含行动者自己**）；
  **HEAD 的代码**（`style_reward.threat_seats(obs, obs["seat"])`）则是**只数别家**，
  理由：立直之后只能摸切、**没有选择权** ⇒ 那几行不是降り决策。
- **两者的差已逐位解释**（`_fold-selfriichi-probe.py`）：`# {学生出牌 ∧ 自己立直 ∧ 别家都没立直}`
  = **4892**（正是 `threat_rows` 差）、其中打出的牌对自己也是現物 **287**、减去"自己与别家都立直、
  对别家現物但对自己不是現物"的 **191** ⇒ `fold_rows` 差 **96**、`push_rows` 差 **4796**（吻合）。
- **结论**：本轮链是在**字面口径**下付的奖，而判据侧/后续读数按**当前代码口径**（只数别家）；
  两者差 **96/1795 = 5.3%** 的付奖行。⛔ 今后 §1 必须写成"`obs.riichi` 里**别家**为真"，
  并在口径冒烟测试里把"含不含自己"当成一条**被验的**口径（而不是措辞）。
