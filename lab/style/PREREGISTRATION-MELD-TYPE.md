### 6.0 判据侧的**方向性**修正（(A)，**先于跑链**落地并自证）
- 旧规则（§3 末）是**方向无关**的机械式：「CI 上界 < 0 **或** 点估计 < −tol ⇒ 越界」⇒ 把 `deal_rate`
  Δ=−0.992（上界 −0.136，**放铳变少 = 有利**）误报成越界。**这不是数据问题，是判据方向问题**。
- 新规则：每个伴随质量量标注**坏方向** `bad_when`（**由轴的意图定，⛔ 不由统计量定**）：
  `win_rate` / `meld_rate` / `avg_win_score` / `riichi_rate` / `riichi_win_rate` ⇒ **下降为坏**（`down`）；
  **放铳率 `deal_rate`** 等"越少越好"的量 ⇒ **上升为坏**（`up`）。
  越界 ⇔ **在坏方向上显著**（按符号取**单侧** CI）**或** 点估计越过该方向的容忍带：
  `down`：`hi < 0` **或** `Δ < −tol`；`up`：`lo > 0` **或** `Δ > +tol`。
- 实现点：`tools/w-ladder.py` 的 `companion_verdict`（+ `COMPANION_BAD_WHEN` 表 + `PARENT_BAD_WHEN`）；
  ⛔ 不动 `tools/style-vector.py`、⛔ 不动 `python/mahjong_ml/v4/gate.py`（那是闸门，不是本判据）。
- **为什么方向必须按轴意图定**：这条判据问的是"这笔钱是不是**买到了效果却付出了代价**"。代价是**有符号的**
  —— 同一个 Δ=−0.99pp，落在"要和了率"上是要买的（坏），落在"放铳率"上是白赚的（好）。方向无关的规则
  等于**把"变好"也判成越界** ⇒ 任何**同时改善防守**的轴都会被误杀，判据会把正确方向的动作淘汰掉。
- **缺省口径回归**：`down` 类的量走的是与新规则**逐字相同**的那条式子 ⇒ 既有产物**逐字节不变**（对拍见 §7）。
