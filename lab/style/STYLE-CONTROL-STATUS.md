## 4. 族级结论（最重要：一次说清"什么叫推得动"）

- ✅ **推得动的 = "进攻手段"族**：`riichi`（立不立）· `meld`（鸣不鸣）· `dama`（能立而不立，行级）· `pon`（鸣什么）。
  共同点 = **奖励落在"真实发生过的一个动作类型/频率"上**（宣言 / 鸣牌 / 弃和 / 碰）：一行一次、发生次数多、方向单一。
- ⛔ **推不动的 = "风险处理"族**：`fold`（押し率/降り率）。它问的是**"在给定威胁状态里选哪个方向"**（打危险牌还是安全牌），
  两口径付奖行率 1.04% / 1.68%、CI 均含 0；而且是**付钱路按名义剂量付满之后仍然没位移** ⇒ 不是剂量问题。
- ⚠ **同族降级 = "手作り"族**：`H ドラ保持` · `I 染め志向` · `J 対子志向`（普查实测 J 的判别力 **≈0**：`deal` **19.7% vs 19.7%**；
  H/I 也全是"打牌行里选哪个方向"）⇒ **不再单独立轴**，只当**特征/读数**。
- ⇒ **一般判据**：**"动作类型/频率"能用每行 ±1 的行级奖励推**；**"在给定状态里选哪个方向"用每行 ±1 的教学不会** ——
  后者的信用分配要落到"**同一状态下另一条动作**"上，须改成**同状态下的对比式优势**（advantage 式的相对比较）。
  ⚠ **这是尚未验证的设想**：本报告只给机制解释 + 同族证据，⛔ **没有做过任何对比式奖励的实验**。

## 5. 判据工程清单（五条硬判据 + 两条流程；每条配一个**实际踩到**的例子）

1. **判据必须与奖励对齐**（付奖行覆盖的决策集 ⊇/≈ 判据的分子集）。反例 = `dama` 第一轮：奖励侧付奖行是**行级**"能立而不立"（524 行），判据侧却拿**手级** `dama_rate`/`dama_wins`（510 小局）⇒ **只有 8% 重叠**（对齐后 12%，两轮同一结论）⇒ 一代主判据仅 +0.015 场/席（SE 0.027）**没位移**。正解 = 行级付奖行配**行级**判据 `decline_rate` + 逐项对账。
2. **普查必须按"最终形态"量**。反例 = `立直巡目`：中间快照 **1.91%/行**（机会行 2.23%），到最终口径（只认"宣言立直那一行 ∧ 巡目 ≤ T"、
   晚立直一分钱不付）掉到 **0.79%/行** ⇒ 同一根轴从"过门槛"变成"不过门槛"；⛔ 拿普查快照当付奖行率会得出**相反**结论。
3. **门槛与主判据必须同口径**。反例 = `fold`：同一份数据 **四席 7216/695088 = 1.186%** 过线 vs **学生席 0.9891% 不过线**（结论翻转）；
   定稿口径 = 学生席 **1.0394%** vs 四席 **1.0381%**。⛔ 不许"一个口径过门槛、另一个口径出主读数"。
4. **对账基准必须与判据侧同版代码**。反例 = `fold` 冻结审计账 `audit/v4-wl-fold-c1-g01.json` 与 HEAD 的奖励代码差 **threat +4892 / fold +96 / push +4796**（逐位根因 = 训练当时那版 `threat_seats(obs)` **不带 seat**，把"行动者自己已立直"也算被威胁）。⇒ ⛔ 冻结账不能当基准；基准换成**当前奖励代码在同一份轨迹上重算**，差异**照实报**、不静默抹平、也不删它。
5. **伴随质量量的越界必须按"轴的意图"定方向**。反例 = `pon` c1：放铳率 **Δ=−0.992（上界 −0.136）**，旧的方向无关规则（`hi < 0` ⇒ 越界）把**放铳变少（有利）**误报成越界；合并读数 −0.632（上界 −0.005）同样命中。
   规则 = `down`（和了率/副露率/立直率/打点/立直后和了率 **+ 各轴自己的目标量**）⇒ 越界 ⇔ `hi<0 或 Δ<−tol`；`up`（**放铳率**、巡目）⇒ 越界 ⇔ `lo>0 或 Δ>+tol`；容忍带**随单位走**（打点 = **150 点**，依据闸门侧同量纲 `win_points:150`；⛔ 不套 2.0pp）。
6. **流程① 口径冒烟测试**（跑链之前、≤50 场、强制）：把"奖励侧集合 == 判据侧集合"**逐键 + 逐行集合**验一遍（对称差必须 0）。
   踩坑 = `fold` 上一轮这里错了三轮、墙钟从 **110 min 涨到 195 min**；`pon` 的首版判据自己漏了"只数学生席 / 只数 `pon:`"（把 466 行别家的行算进规则集），**被冒烟当场抓住**。
7. **流程② 读数路径坏了不许"手搓一份绕过"**。实测三处：`post --reuse` 只重跑读数（轨迹不齐**报错**、不静默降级）；`quality --pre/--post` 曾因 `traces/` 与 `traces-post/` **目录同名**而按错 tag 找风格向量（预/后两侧各差 89 个手级量）；付钱路曾用**行内下标**当键、而手上是**每场** `step` ⇒ 钱只落在下标恰等于 `step` 的少数行上（审计账 `paid_rows` **1578** vs 列 `nonzero_rows` **150** = **9.5%** ⇒ 那条链的剂量只有名义值的十分之一）。三条都按"**修工具 + 记偏离**"处理。

## 9. 打点裁定与激活模型（2026-10-11 用户架构级裁定 · 零算力 · 与 `NOTES.md` §6.5 末尾、`AXIS-CANDIDATES.md` §8 同措辞）

- **裁定（原文意思）**：专家风格模型**可由附加的激活模型按情境选择启用** ⇒ **单线不必全局均衡**（一条线只在自己被激活的情境里负责）。
- **判据后果**：`rank_points` **保留为唯一硬门**；打点 `avg_win_score` 由「越界判据」**降级为风格签名坐标**，只在**结构性强界**时报警（⛔ 不再按 §5 第 5 条的 **150 点**带把它当否决项）。
- **打点判据 = 三个坐标 + 一个主尺度**（2026-10-11 用户两步裁定；⛔ 作废上一批那行「单一 −600 点 / incumbent ≈90%，取宽」—— 它不再生效）：**主尺度 = 全有局（每小局，含流局/别家和）× 净得失点**（与 `ΔEV`/`rank_points` 同族）⇒ **主判据永远落在它**（或闸门的**每场顺位点**上）；分档**按坐标**（⛔ 不是按整条轴一刀切），②③ 都是主尺度的**分解项**（基数矩阵见 `DEFENSE-EFFECTIVENESS.md` §5）。

**修正后的分档（按坐标）**：

| 坐标（基数 × 量） | 守（安全优先） | 速（速度优先） | 攻（打点优先） |
| --- | --- | --- | --- |
| **① 机会量**（全有局） | 记录 | **收益需显著** | 记录 |
| **② 机会质量**（**和了局**打点） | **只记录** | **换算后判（≤5×SE）** | **严判（CI 下界 ≥ 0）** |
| **③ 风险**（全有局放铳/失点） | **主门 = ΔEV** + `rank_points` | 伴随（不许显著变差） | 伴随（不许显著变差） |

- **两个量必须分开判（同一条判据的两个基数，⛔ 别混）**：**总得点**（**全有局**净得失点 = **量×质×险**，**主尺度**）vs **平均打点** `avg_win_score`（**和了局**和了点 **除以和了次数** = **条件质**，**坐标**）。
- **两条代价（否则会误判）**：① **功效随基数变化** —— `和了局` 基数 n ≈ 全有局的 **~20%** ⇒ **SE 放大 √5** ⇒ 同一效应要 **×5 场次** ⇒ 故"和了局打点"**只当坐标、不当主判据**；② **有条件基数的选择效应是内生的** —— 线会改变"**赢哪些局**" ⇒ 配对比仍成立，但只能解释为"**你赢的那些局值多少钱**"，⛔ 不是"创造了多少价值"。⚠ 由此也解释了 **"进攻线不一定打点不下降"**（理由：**点炮概率在变大**）⇒ 打点升降**不能替代**主尺度。
- **尺子（只能引用已实测，⛔ 不改数、不编新数）**：每席 ≈**22,700 手**时 **平均打点 SE ±71 点**、**每手收支 SE ±35 点**（原表 = `NOTES.md` §6.5 风格剖面 / `DEFENSE-EFFECTIVENESS.md` §4；项目级汇总见 `PROGRESS-SUMMARY-2026-10-10.md`）。
- **现有四轴归属（供核对）**：`riichi` = **速偏攻**（打点未动）· `meld` = **速**（**−360~−410 点 ≈ 5.1~5.8×SE** ⇒ 落**②"机会质量"的中带边界**，按**换算**判而非直接否决）· `dama`/`pon` = **速**（打点基本未动）· 未来**押し引き = 守**（主门 = ③ 的 ΔEV）。⚠ **待预注册冻结后才用于判决**。
- **战略简化**：**"少量可靠风格 + 一个激活模型" > 铺满 QD 网格**（router 不需要稠密网格 ⇒ §8 第 1/2 项不再是我方必经）。
- ⚠ **对 §2 的直接影响**：`meld` 那 **−360~−410 点**（五链一致）在**按坐标**的分档口径下走**② 机会质量 · 速线的换算**（**不是**"单一数值放宽"、也不是"一刀切否决"）—— 它是**"速度型风格"的签名**（要买的正是"更快、更小"），**纯亏才否**、⛔ 不是代价越界；`pon` 的 −65.8 点等同类打点读数一并按**坐标（签名）**读。

## 10. 专家 + 激活域架构（⚠ 待验证架构假设 · 2026-10-11 · 零算力 · 与 `NOTES.md` §6.5 末尾 / `AXIS-CANDIDATES.md` §8 / `DEFENSE-EFFECTIVENESS.md` §8 同措辞；⚠ 用户原话"**我们祈祷这是有效的**"）

- **裁定（原文意思）**：**不再奢望"一次性训练出全能模型"，改为用多种风格模型替代**（每个都有自己的独特意义）⇒ **单个模型不必"完全提升"**，只需在**它自己被激活的那块"局部分母"（激活域 D）上提升**；全局账由**激活模型（router）**按局面逐个挑专家来拼。
- **术语澄清（⛔ 别与 §9 混）**：**度量基数**（全有局 / 和了局 / 听牌局）＝"**除以什么**"（单位问题，就是 §9 的三坐标 + 主尺度）；**激活域（局部分母 D）**＝"**在谁身上算**"（该专家会被启用的那批局面）。两者**复合**：**单模型成绩 =（某量）在（它的激活域）上算**；**全局成绩 = router 逐局面挑专家后的总账**（主尺度仍是 **`全有局 × 净得失点`** 或闸门的**每场顺位点**）。
- **单模型判据（四项）**：**条件提升** = 该专家在**自己的域 D** 上的配对 `ΔEV`（同 seed / 同牌山）⇒ **D 上显著为正 = "在自己地盘上赢"** · **覆盖率** = `P(D)` ⇒ ⛔ **不能太窄**（否则总账无感、噪声吃掉）· **泄漏** = 被启用但**本该由别人处理**的局面占比 ⇒ **越低越好**（激活模型替它背锅）· **域外表现** = 在 D 之外变差多少 ⇒ ⛔ **不计入单模型成绩**（由别人接管），**但必须记录**。
- **三个失败模式（⚠ 均"待验证"）**：① **域切不干净（泄漏）** ⇒ **集成绩 < 最好的单模型**；② ⛔ **条件提升不可组合**（各自域里都赢、但赢的是**同一批局面** ⇒ **互补性为零**）⇒ **最致命**；③ **域太窄** ⇒ 覆盖率低、总账无感。
- **神谕路由增益（ceiling）= 训 router 之前唯一能回答"值不值得"的离线量**：`ceiling = 「逐局面挑最好的专家」的总成绩 − 「最好的单个专家」的总成绩`；**若 `ceiling ≈ 0` ⇒ 任何激活模型都救不了 ⇒ 立即止损**。
- **ceiling 的测法与成本（✅ **已跑**：2026-10-11 共同评测 · 五臂 × 同 `seed_base` = 51027301 × 1000 场 · 零训练/零闸门）**：让现有**四条风格线 + 现任**在**同一批牌山 / 同 seed** 上各跑一遍、**逐小局**记录结果，再按上式逐局面取最好 ⇒ **实测成本（2026-10-11 已跑）**：**五臂 = 现任 / `riichi` / `dama` / `pon` / `meld` × 同一 `seed_base` = 51027301 × 1000 场**（同风格桌 + `--rotate-perm`、逐手全轨迹；实测采集 1506.8 s + 5 次 `style-vector.py` 读数；逐手轨迹读完即删）。**结论 = NO-GO**：可学习 ceiling = **+36.7 点/小局**（SE 26.22，t=1.40，**CI[−13.7,+89.1] 含 0**）= 无限制神谕（+3372.0 点/小局）的 **1.0%**；`ρ(Δ神谕, 现任自身得分) = −0.531`（剔现任最差 20% 后增益掉 35%）⇒ 神谕几乎全是均值回归；**7 种分层口径全部 |t|<2**；域几乎不相交（`meld∩pon` 0.412、`riichi∩dama` 0.170、其余 ≤0.009）⇒ 失败模式②（域撞车）**不成立**，否掉的原因是**「天花板不可学」**（细节数据根 `w-ladder\ROUTING-CEILING-COMMON.md`，118 行，含 §6.1 逐臂核对）。
- **对现有四轴的下一步含义**：归属照旧（`riichi`=速偏攻 · `meld`=速 · `dama`/`pon`=速 · 未来押し引き=守）；但**要当专家**，每条轴还必须**自己给出域 D 与覆盖率 `P(D)`**（**未记录**）—— ⛔ 域 D 是"哪些局面可交给它"，与 §9 的**度量基数**是**两个维度**，成绩一律**同时**标出（**度量基数 × 激活域**）。
- **结论（2026-10-11 共同评测后）：NO-GO（唯一例外 = `riichi` 臂本身更强）** —— 状态限制神谕对最好单臂的样本外增益 ≈ 0（1.0% 的无限制神谕、CI 含 0），router 训练轮**不值得投**；止损只对"神谕 router + 其余四臂"成立，`riichi` 单独拿来用**已成立**（+6.21 马点/场 CI[+2.90,+9.51]，与强度闸门 `+3.26[+2.29,+4.26]` 一致）。

- **实验 A《分歧域可学性探针》定论（2026-10-11 · 零训练 · 报告 `EXPERIMENT-A-DIVERGENCE.md`，58 行 + `_experiment-a.json`）**：两臂 `wl-riichi` vs `wl-meld`（纯 argmax）同 `seed_base=52870101` × 1000 场 ⇒ **D 上样本外路由增益 +29.23 点/小局（SE 29.79，t=0.98，CI[−29.15,+87.61]）含 0**；¬D **+0.00**、¬D∧前缀干净（n=288）两臂账**逐位相同 ⇒ 神谕恒 0**、ρ(神谕, 基准臂自身得分) **−0.421**（剔最差 20% 掉 43%）、Δ 随分歧行 0→1→2-3→4+ = +545.7→+427.2→+42.5→**−503.3** ⇒ **多专家 + router = 原理性不可行**（换判据没改变任何东西：+29.23 稳落在旧 CI[−13.7,+89.1] 内）。**机制** = 分歧 13.05%/行、覆盖 78.47%，但 **769/1000 场在第 0 小局内一次性分岔**（真·同状态小局仅 2.5%）⇒ 之后两条轨迹互不相干 ⇒ 按结果后验选臂**退回均值回归**。唯一未被否掉的杠杆 = **换候选臂**。
- **设计结论（最重要）**：**互补的充分条件不是"两套不同策略"，而是"两臂行为相同直到某个可辨状态、然后在该域上刻意分歧"** ⇒ 实现形态 = **共享主干 + 域条件化分叉**（MoE / 共享 trunk + 专家头 / 单网多域）；⛔ **两个独立训练出来的网不行**。
- **判据句**：**多专家路线的闸门 = 两臂必须"同到可辨状态再分歧"；按结果后验选臂在麻将里注定是均值回归。**
- **算力与卫生（如实）**：**40 min（≈2,420 s）> 20 min 预算**（超支主因 `v4net` 逐行 JSON 解析 ≈2.9 ms/行）；**0 次 JVM 崩溃**；原始失败 **1 次**且**不是 JVM 崩溃**，是我自己把落盘路径写错（`FileNotFoundError`）；⛔ 全程未跑训练/采集/闸门。
