# 预注册：`riichi_turn` 轴（**早立直** · 阈值 T=8）· 1 链 × 1 代 · 同权点剂量

> 上级 2026-10-11 指定（路线 1 第一根轴）。**写在跑之前，跑之前不许改**。⛔ 不跑闸门、不加第 2 条链、不建 QD 网格；配方与 riichi/meld/dama 各轮**逐字相同**（`v4-expert-defrep-g10` + 风格桌 + `--rotate-perm` 24 排列平均 + `MAHJONG_PRODUCER=cpp`），只换**轴**与**剂量**。

## 1. 轴 / 付奖行 / 阈值 / 剂量 / 伴随量

- **付奖行**（`ROW_ACTION_TURN`）= **宣言立直的那一行**（与既有 `riichi` 轴同一行规则）**且**该行 `obs.player_draws` ≤ **T=8**；⛔ **方向单向**：晚立直（巡目 > T）那一侧**一分钱都不付**。
- **T=8 的理由**：普查（`AXIS-CENSUS.md`）实测立直巡目 均值 **9.28** / 中位数 **9**（n=3261，与 `avg_riichi_turn` 同数）⇒ T=8 = **均值量级**；⛔ **换成按巡目衰减**（本轮不做）会同时给"晚立直"付钱（方向不再单向）且白化对象从 Bernoulli 变连续量。
- **剂量**（逐行同权点 `Y/Z = 1/√2`，按 `parity_note` 的逐行读数校准）：`k = √((1−μ)·q(1−q)/μ)`，普查给 `q/μ = P(no_deal|宣言行) = 89.2%`、`μ ≈ 0.9%` ⇒ `k ≈ √0.892 = 0.9444`；`δ = 5062.6 / 5191.4`（meld 校准反解）⇒ `w* = δ/k ∈ [5361,5497]` ⇒ **`w = 5400`**（⛔ 不为做大效应上调）。
- **伴随量** = `no_deal`（普查 89.2% 真门）；闸门 **`blocked_rows > 0`**（`ROW_PAIR_MUST_BLOCK`，在**实测**层证明非恒真 —— 立直者**仍可能放铳**，故 `IMPLIED_PAIRS` 的静态表对这对不报错）。
- ⚠ **与既有 `riichi` 轴共存**：同**决策点**的"**时机**"维度，两轴可在**同一条轨迹**上分别开；默认（不给 `--style-bonus`）与既有各轴**逐位不变**。

## 2. 链 / 主判据 / 伴随量 / 止损

- 配方：`--style-bonus 'riichi_turn=5400:no_deal'` + `--style-bonus-mode decision`、**1 链 × 1 代 × 1000 场**、`-NoGate`；链 `v4-wl-rt5400-c1-c1`（seed 24620081 / 采集 `seed_base` 24620082，与历次各族 24310011..32 / 24310041 / 24310091-92 / 24620011 / 24620021 / 24620051-52 / 24620061-62 / 24620071-72 / 闸门 40970001-4 **都不相交**）。
- **主判据**：`post` 补采（末代权重、**同 seed 逐场配对**，自证 seed/学生席不一致 = 0）的 **每场每席平均立直巡目**（`riichi_turn_sum / riichi_turn_known`）配对 Δ + 95% CI；**方向为"降"** ⇒ **Δ 为负且 CI 排除 0** = 一代就把立直时点**推早**了。辅 = 聚合 `avg_riichi_turn`。
- **对账（硬）**：付奖行数 == 审计账 `action_rows` == `declared_turn ≤ T` 的宣言行数（三个独立来源逐项相等；不等 ⇒ **不出读数**）。
- **伴随量（护栏，单侧）**：立直率 / 和了率 / 副露率 / 放铳率 / 打点（`avg_win_score`）/ 立直后和了率（`riichi_win_rate`）+ `quality`（越界 ⇔ `CI 上界 < 0` **或** 点估计 < −tol）。
- **止损**：任一伴随量越界，或 `wins`/`deals` 同量纲 Δ ≤ ∓0.10/场/席 ⇒ **立即结案**，⛔ **不事后改判据**。

## 3. 预先写明：三种结果各自意味着什么

- **没位移（CI 含 0）**：付奖行率 ~0.9%/行（低于普查 §4 的 1%/行门槛）⇒ 与 `dama`（0.32%/行）同类：结论是"**这个时机维度在 1 代 × 1000 场的信噪比下测不动**"，下一步换**付奖行口径**（例如只在"听牌后第一次"付）或加场次，⛔ 不是加剂量。
- **方向反了（Δ 为正且 CI 排除 0）**：这笔钱在推**晚立直** —— 最可能是"付奖行与伴随量不同源"导致的反向信用分配 ⇒ 判定该轴（在该口径下）不适合行级正推，改回"只当判据侧读数"。
- **方向对但代价太大（任一伴随量越界）**：按 §2 止损结案，并写清"立直可以推早、代价是什么"。
