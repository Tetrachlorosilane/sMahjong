## 1 冻写稿要点（摘要，逐字稿见计划文件）
两臂同 seed、同对手、学生席恒 = 0：**A0** = 起点网/现任 `v4-expert-defrep-g10`（argmax）；**A1** = 风格网 `v4-wl-dec6170-4g-c2-g04`（**wl-riichi**）。同状态判据 = 逐局取**第一处** `chosen` 不同的决策行，且该行之前全部学生决策的 `md5(obs)` **逐位相同**、`legal` 逐位相同。目标量 = `Δ = hand_delta[A1][席0] − hand_delta[A0][席0]`（净得失点/小局），标签 = `sign(Δ)`（Δ=0 丢弃并计数）。特征只许公开观测白名单 + 两个候选动作的动作键。学习器 = 小 MLP（本环境无 sklearn/scipy/gbdt）。切分 = **按场** 5 折 GroupKFold。判据 = 样本外 AUC 的按场 cluster bootstrap 95%CI 是否排除 0.5。

## 5 判决（按预注册 §5，⛔ 判后未改判据）
**方向族封存。** 两条都触发：
1. **主判据**：OOS AUC **0.4799**，CI95 **[0.4300, 0.5302] 含 0.5**（点估计还在 0.5 之下）⇒ 走「测不出/不可学」支。
2. **增益门槛**：交叉拟合增益占神谕 **0.060 ≪ 0.2**；且该增益**不能**算技能 —— AUC < 0.5（排序比随机差）、增益只比「总是选 A1」高 +31 点/小局，来源是**选择比例**（判正 72.6%）而非识别力。
3. **安慰剂不比主判据弱**：最强安慰剂（③只用动作键）AUC **0.5290**，主判据 − 最强安慰剂 = **−0.0491** ⇒ 连"优于安慰剂"这句话都不成立。
4. 计划要求的**均值回归检查独立报警**：`ρ(Δ, A0 自身该局得分) = −0.694`（旧实验 A 是 −0.421…−0.531）⇒ 配对结果差里主导成分仍是"基准臂这一局倒不倒霉"，不是"状态识别出的对比优势"。
⇒ **方向族（状态条件下的方向选择）在本口径下无可学对比信号；按预注册彻底封存。** 结论**条件于该 seed 族**（单 seed 52940001）。

## 6 残余风险（照实记，不掩盖）
1. **功效有限，不是"证明 AUC=0.5"**：n=526、CI 半宽 0.050 ⇒ **MDE(AUC) ≈ 0.55**（只有 AUC≥0.55 才测得出来）。同状态配对天然 ≈ **1 场 1 行**（真·同状态小局占比 526/6,511 = 8.1%），要把 MDE 压到 0.025 需 **≈2,100 行 ≈ 2,400 场/臂 = 本预算的 4×**。本判决是"**这个分辨率下没有可学信号**"，不是"绝对没有"。
2. **后继策略混淆**（计划已登记）：分岔点之后两臂各走自己的网 ⇒ Δ 混合了「该决策的动作差」与「后续两个网的整体强弱差」（A1 全场收支持平 +34 点/场更好）⇒ Δ 均值 +138.78 里含这个系统性成分，**不是**纯动作优势。
3. **标签信噪比极低**：σ(Δ)=7,589 点 vs 均值 139（SNR≈0.018）；神谕 E[max(0,Δ)]=2807 点/小局里绝大部分是**运气**（旧结论一致：无限制神谕几乎全是均值回归）。
4. **`step` 不是同状态判据**（实测是每场累计计数，跨小局不清零），同状态只看 `obs`/`legal` 逐位；`dy=0` 的 803 局按预注册丢弃 ⇒ 样本偏向"该局学生与结果有关"的情形。
5. 单/少数牌山（1 个 seed、同 3 个对手网的风格桌）⇒ 不外推。
6. 学习器容量/正则未做敏感性扫描（计划冻结为单一小 MLP）；**不排除**"换学习器/换特征编码"能挤出一点，但按预注册不得改判据。
