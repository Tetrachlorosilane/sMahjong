## 1. 三层必须分开：① 行为 ② 有效性 ③ 判决口径

- **① 防守行为（可测、便宜）**：只读轨迹的 `legal` / `chosen` 就能落行 —— `AXIS-CENSUS.md` 的 1000 场普查就是这么数的。
- **② 防守有效性（贵）**：问的是"**同一状态下**押比降**多赚/少赔多少**"⇒ 必须**同状态配对或反事实**。
  ⛔ **单看放铳率是选择效应**：谁去降り、谁去押，本来就是**自选择**的（手牌 / 点棒 / 顺位 / 巡目都不同）。
- **③ 判决口径**：**配对 + 多套牌山 + CI + 护栏**（流程 = `PREREGISTRATION-TEMPLATE.md` 四条；判据工程 = `STYLE-CONTROL-STATUS.md` §5）。
- **点明坑（真实例子）**：`AXIS-CENSUS.md` 四列表 **A vs A″** —— 被立直威胁时**押**的 `deal` **28.7%**（3015/10506）
  vs **降**（切现物）**21.0%**（3293/15664），判别力 **+7.7pp**（该差值写在普查"实现顺序"表第 3 行）。
  ⛔ **这只是判别力旁证，不是有效性证据**：两组行**不是同一批状态**（是"打了危险牌"与"打了安全牌"的**自选择**切分），
  差 7.7pp 既可能是"降り省了铳"、也可能是"本来就更危险的手才去押"。⚠ 佐证：`fold` 轴就是拿这份判别力做的两口径，
  结果**行为量一动没动**（付奖行率 **1.04% / 1.68%**，主判据 Δ=**−0.063pp**[−0.396,+0.270] 与 **+0.148pp**[−0.267,+0.563]
  **CI 均含 0**，见 `STYLE-CONTROL-STATUS.md` §3）⇒ **有判别力 ≠ 判得出有效性**。

## 3. ② 有效性怎么量化：正确量是**期望收支差**，不是放铳率

- `ΔEV(状态) = EV(押 | 状态) − EV(降 | 状态) = Δ(和了点) + Δ(被ツモ点) + Δ(放铳点) + Δ(流局/听牌罚符)`；
  **防守有效 ⇔ ΔEV < 0**。
- **A 路 · 分层条件比较（便宜）**：按 **`巡目 × 现物数 × 是否听牌 × 点棒/顺位`** 分层、**层内比**，**只读轨迹**。
  残留混杂仍在（`AXIS-CENSUS.md` "实现顺序"第 6 行已记：`K 局面依存` 的"顺位差本身与牌山运气相关"⇒ 它是**二阶层**）。
- **B 路 · 同局面反事实（因果、中高成本）**：用引擎**定向钩子** `debugPushDiscard` 那一族
  （`server/.../game/Round.java` L674；同族 `debugClaimOutcome` L3143 / `debugDrainWallTo` L1011，见 `AGENTS.md` §4）
  对**真实威胁状态**做"**强制打危险牌 / 强制打安全牌**"的**同牌山同手牌**重放。
- ⚠ **B 正是"方向族"若要可训所需的同状态对比式优势的来源**（`STYLE-CONTROL-STATUS.md` §4 的"同状态下的对比式优势"，
  ⛔ 该设想**尚未验证**）。⚠ B 的**可行性未记录**：钩子在**自对弈生产者**（java / cpp 两路）里能否**按状态重放**，
  本批未确认（零算力）⇒ 见 §7 / §8。

## 5. 判定表（先写死，再谈实现）

| 行为量（§2） | ΔEV（§3） | 护栏 | 判决 |
| --- | --- | --- | --- |
| **动了** | **显著为负** | **不破** | ✅ **有效且可训**（才谈奖励改造与闸门新口径） |
| **动了** | **不显著** | 不破 | ⚠ **"降了但没省"** ⇒ 该轴只算**风格**（签名坐标），⛔ 不算**强度** |
| **没动**（**现状**） | 无从谈 | — | ⛔ **先解决"能不能推"**（别先谈有效性） |

- **"显著"的定义**：同 seed **逐场配对** Δ 的 95% CI **排除 0**（方向 = 负）；多套牌山下**逐套同号**。
- **护栏**：顺位点 CI 下界 ≥ **−1.0**（`STYLE-CONTROL-STATUS.md` §2 的闸门口径）+ 止损量 `deals` ≤ **+0.10**/场/席（预注册）。
- **基数（"分母"）先定 —— 基数矩阵**（2026-10-11 用户同批追加裁定；⚠ **打点不是"固定带"的问题，更该先定分母**；奖励侧 = **每决策行**、闸门 = **每场**收支/顺位）：

| 基数 | 量 | 角色 |
| --- | --- | --- |
| **全有局**（每小局，含流局/别家和） | **净得失点** | **主尺度**（同时装"质"与"险"，与 §3 的 `ΔEV` / `rank_points` 同族） |
| **和了局**（仅获胜局） | 和了点 | **机会质量**坐标（⚠ **有选择效应**：进攻线赢的可能是**便宜手**） |
| **听牌局 / 有和了机会局** | 和了点或和了率 | 把**机会量**与**机会质量**分开 |

- **主判据永远落在"全有局净得失点"（或闸门的每场顺位点）这个主尺度上** —— 机会质量 ② 与风险 ③ 都是它的**分解项**（⛔ 别拿分解项当主判据）。⚠ **进攻线不一定打点不下降**（理由：**点炮概率在变大**）⇒ 打点升降**不能替代**主尺度。**分档按坐标**：① 机会量（全有局）守=记录 / 速=**收益需显著** / 攻=记录；② 机会质量（**和了局**打点）守=**只记录** / 速=**换算后判（≤5×SE）** / 攻=**严判（CI 下界 ≥ 0）**；③ 风险（全有局放铳/失点）守=**主门（ΔEV）+ `rank_points` 护栏（本节的 −1.0）** / 速·攻=**伴随（不许显著变差）**。⚠ **守线在 ② 上"只记录"**：**别家荣和/自摸会机械地压低自家总得点，而这是必要的**（降り = 用打点换失点）⇒ 拿它当门等于**惩罚"正确地降り"**。
- **两条代价（否则会误判）**：① **功效随基数变化** —— `和了局` 基数 n ≈ 全有局的 **~20%** ⇒ **SE 放大 √5** ⇒ 同一效应要 **×5 场次** ⇒ 故"和了局打点"**只当坐标、不当主判据**；② **有条件基数的选择效应是内生的** —— 线会改变"**赢哪些局**" ⇒ 配对比仍成立，但只能解释为"**你赢的那些局值多少钱**"，⛔ 不是"创造了多少价值"。（三处同措辞：`NOTES.md` §6.5 末尾 / `STYLE-CONTROL-STATUS.md` §9 / `AXIS-CANDIDATES.md` §8）
