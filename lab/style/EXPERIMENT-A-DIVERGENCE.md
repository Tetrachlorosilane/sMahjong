## 3. 分歧率与覆盖（主臂 `riichi` 的 171,672 条学生决策行）
- **逐决策行分歧率 P(两臂 argmax 不同) = 13.05%**（22,397 行）。分层：`turn` 13.01% / `claim` 13.18%；摸牌数 1–6 **13.73%** / 7–12 13.23% / 13+ 9.40%；**别家已立直 17.06% vs 无 11.76%**。
- **逐小局覆盖率 P(D) = 78.47%**（8,921 / 11,369 小局至少含 1 条分歧行）。
- **"同一状态"自证**：两臂 `(game, hand_no, step)` 同键 38,664 条，其中 **obs 指纹逐字节相同 11,241 条（29.1%）**；在这**真·同状态**行上分歧率 **11.60%**。⚠ 但每场"真同状态"前缀只有 **中位 5 条学生行**（p90 22，最大 68；全场均值 171.7）⇒ 两臂在**第 0 小局内就分岔的有 769/1000 场**，前 2 小局累计 936/1000，**1000/1000 场全都分岔**；真·同状态小局仅 **288/11,369（2.5%）**。

## 4. 主判据 + 两个对照（逐小局配对；基准 = **拟合折上更好的那条臂** = `riichi`）
配对自证：`seed_base` 两侧 52870101、1000/1000 场、**seed 不一致 0 · 学生席不一致 0 · 另三席策略表不一致 0**；共同小局 10,648（并集 12,091）。对齐自证：`v4net` 的 `argmax` 与实际打出的 `chosen_index` **逐行 100.000% 相同**（171,672/171,672，step/nlegal 0 不一致）。
- **主判据（D 上，n = 8,357 小局）**：样本外（奇数场拟合 / 偶数场评估，两方向合并，12 桶 = kind × 摸牌档 × 他家立直档，桶内选训练折均值高的臂）路由增益 = **+29.23 点/小局，SE 29.79，t = 0.98，95% CI [−29.15, +87.61]**（按场聚类 SE 29.31，t 1.00）。⇒ **CI 含 0**。
  · 同族 **in-sample** 桶神谕 +80.58（t 2.87）· 逐小局**不设限**神谕 +1,805.76（SE 41.4）⇒ 掉的是**泛化**，不是容量。
- **对照 1（¬D，n = 2,291）**：样本外增益 **+0.00**（规则在拟合折上一次都没翻向 `meld`）；¬D 上 `riichi` 对 `meld` 的**无条件**配对 Δ = **+545.66**（SE 105.39，t 5.18）⇒ 指示量的补集里没有任何可路由的空间。
  · **对照 1b（¬D ∧ 前缀干净，n = 288 / 216 场）**：两臂逐小局账**逐位完全相同**（dX == dY == 852.08），神谕增益 **恒 0** ⇒ 机械自证：不分岔的地方路由**不可能**有增益。
- **对照 2（均值回归）**：`ρ(逐小局神谕增益, 基准臂自身该小局得分) = −0.421`；剔除基准臂最差 X% 后神谕增益 0% **+1,613.9** → 10% +1,104.5 → 20% **+919.2**（−43%）→ 50% +598.7。`ρ(d_riichi, d_meld) = 0.376`（与报告的非学生席底噪 0.25~0.40 同量级）。
- **分级对照（小局内分歧行数 → Δ(riichi−meld)）**：0 行 **+545.7**(t 5.18) · 1 行 +427.2(t 3.97) · 2–3 行 +42.5(t 0.41) · **4+ 行 −503.3**(t −3.48) ⇒ 分歧密度越高，`riichi` 的相对优势**越小甚至转负**。

## 5. 判据结论 = **原理性不可行（多专家 router 路线可彻底封存）**
**CI 含 0**（主判据）⇒ 按**跑之前写死**的判据：**NO-GO 是原理性的，不是口径/分辨率事故**。而且点估计 **+29.23 与旧 ceiling 的 +36.7 只差 7.5 点，稳稳落在旧 CI [−13.7, +89.1] 内** ⇒ 把选择判据从"已实现收支"换成"两臂 argmax 是否分歧"，**没有改变任何东西**。
**机制解释（本轮新证据）**：分歧**不是散落在各小局的稀疏决策点**，而是**第 0 小局内的一次性分岔**（769/1000 场；真·同状态前缀中位只有 5 条行）。分岔之后，两臂只是**共用同一副牌山、状态互不相干**的两条轨迹 ⇒ "D 上哪个臂更好"退回成旧的均值回归问题，D 拿不到任何额外分辨率。

## 7. 残余风险（⛔ 不因结论为 NO-GO 就不写）
1. **单套牌山 × 1000 场** ⇒ 一切读数**条件于这套牌山**（`52870101`），不等于普遍结论。
2. **分歧指示量与"两臂已经分岔"高度共线**：§4 分级表（0 行 +545.7 → 4+ 行 −503.3）说明它很可能只是"本场是否已分岔"的代理，而不是"哪个动作更好"的状态特征。
3. **只有主臂（`riichi`）跑了双 net 前向**（墙钟所限，见 §8）⇒ 分歧率只代表 `riichi` 的状态分布那一侧；`meld` 侧的对称复算**未做**。
4. 路由器假设空间只有 **12 桶**，可能偏弱；但同族 in-sample 上界 +80.6 掉到 OOS +29.2（CI 含 0）说明掉的是泛化。
5. 逐小局配对**重复计同一场的运气** ⇒ 已并列按场聚类 SE；两者一致。
6. 若将来要"复活"这条线：本轮数据**不支持**任何状态特征能救它（§4 三项对照全否）；唯一未被否掉的只有"**换候选臂**"（`ROUTING-CEILING-COMMON` §7 的同一条）。
