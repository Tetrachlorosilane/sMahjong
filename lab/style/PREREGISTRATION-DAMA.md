# 预注册：`dama` 轴（**默听率** · 能立而不立）· 1 链 × 1 代 · 同权点剂量

> 上级 2026-10-10 指定。**写在跑之前，跑之前不许改**。⛔ 不跑闸门、不加第 2 条链、不建 QD 网格。
> 起点/对手池/座位口径/`-NoGate` 与 riichi/meld 各轮**逐字相同**（`v4-expert-defrep-g10` + 风格桌
> + `--rotate-perm` 24 排列平均 + `MAHJONG_PRODUCER=cpp`）；唯一的新参数是**轴**与**剂量**。

## 1. 轴与付奖行（设计判据）

- **付奖行**（`ROW_ACTION_DECLINE['dama']`）= **立直当时是合法选项、这一行却没选它**：
  该行 `legal` 里有 `riichi:*` **且** `chosen` 不是 `riichi:*`（= 真实行为"能立而不立"）。
- **手级指示量**（`AXES['dama']`）= 该席本小局**未立直**（判据侧 `dama_rate = dama_wins / wins` 的分子谓词）。
  ⚠ 两者**刻意不是同一个对象**（判据量结果、奖励量决策）⇒ `dama` 不套"手级=1 ⇒ 有动作行"的蕴含，
  改成两条**可证伪**结构检查（付奖行那一刻必须还没立直、且必须在首次宣言之前）。
- **伴随质量轴** = `no_deal`（该小局未放铳）。付奖行**不是和了行** ⇒ 不退化（`win=w:no_deal` 的教训：
  和了者 `no_deal` 恒真，实测 `action_rows == paid_rows == 2230`、`blocked_rows == 0`、和了率 −1.02pp）。
  预注册闸门：**`blocked_rows > 0`**（伴随量真的拦下东西）**且** `declined_rows == action_rows`。

## 2. 剂量校准（逐行同权点 = 比值 `Y/Z = 1/√2`）

沿用 `PREREGISTRATION-MELD-LOWDOSE.md` §0 的推导：`decision` 口径下 `Z² = δ² + Y²`
⇒ 同权（塑形列 std `Y` == 结果奖励 std `δ`）⟺ **`Y/Z = 1/√2`**，而 `Y = w·k`、
`k = std(塑形列)/w = √((1−μ)q(1−q)/μ)`（μ = 行级付奖行率、q = 行级**真付奖**率）。
实测（两条独立读数，同一学生同一风格桌）：`k = 0.9611`（30 场对拍集，μ_行=0.002705）
与 `k = 0.9444`（120 场 `v4-sty-a` 轨迹，μ_行=0.002375）；δ 取 meld 校准两条读数反解
（5062.6 / 5191.4）⇒ **`w* = δ/k ∈ [5268, 5497]`** ⇒ **取 `w = 5400`**（区间中点就近取整）。
⛔ 不为了"把效应做大"上调剂量（那就不是同权点了）；跑完把 `pretrain` 日志的
"逐行 std 塑形列 vs 被减奖励 std"原始读数与这里的外推并排贴出来对账。

## 4. 预先写明：一代没位移 / 方向反了，各自意味着什么

- **没位移（CI 含 0）**：与 riichi 轴（`w=14000` 只 +0.39pp、噪声地板 0.85pp）同类 ⇒
  **"信度落在哪一行"不是瓶颈**（付奖行率 ~0.3%，一局 ~0.01 笔钱 ⇒ 信号被小局级结果奖励淹没）；
  下一步不是加剂量，而是换**付奖行口径**（例如只在"听牌后**第一**次能立而不立"付，提高每次数的信度）。
- **方向反了（Δ < 0 且 CI 排除 0）**：说明这笔钱在**推立直**而不是推默听 —— 最可能的机制是
  "付奖行与伴随量不同源"导致的反向信用分配（拒绝立直的那一手同时也让该小局更容易放铳/被自摸）。
  那就**判定该轴（在该付奖行口径下）不适合做行级正推**，改回"只能当判据侧读数"。
- **方向对但伴随量退化**：按 §3 止损结案，并记录"默听率可以推、但代价是什么"。

**判据（先写死；⛔ 结果出来之后一个字不改）**

① **主判据 = 行级 `decline_rows_per_game`**（每场每席"能立而不立"行数；与奖励**对齐**的那个量，
   分子集合 == 奖励侧 `action_rows`/`declined_rows`）。配对读数 = **同 seed 逐场配对** Δ + 95% CI
   （正太近似 `±1.96·SE`），并按 §5 ① 的验收：`decline_rows` / `legal_rows` / 付奖行 / 拦下行 / `mu`
   必须与审计账 `audit/<tag>.json` **逐项相等**（不等 ⇒ **不出读数**，先修判据）。
   链①的既有读数按 `paired/v4-wl-dama5400b-c1-c1-g01-POST.json` 原样引用（**不重算**）。
② **两链合并**：链间 seed 族不同 ⇒ **不能逐场配对**，合并口径 = **逆方差加权**
   `Δ_c = Σ(Δᵢ/SEᵢ²)/Σ(1/SEᵢ²)`、`SE_c = 1/√Σ(1/SEᵢ²)`；**同时**给出等权平均作对照读数。
   另报**链间极差** `|Δ₁ − Δ₂|` 与两链的 `SE` 之比。
   **判"已复现"的口径（写死）**：两条链 **Δ 同号** **且** 合并 CI **排除 0**。
   ⛔ 只要不满足这两条 —— 尤其"合并 CI 含 0"或"两链异号" —— 结论就是 **"未复现"**，
   只报链间散布，**不许**用"其中一条显著"替代。
③ **伴随量（护栏，单侧）**：和了率 / 立直率 / 副露率 / 放铳率 / 打点（`avg_win_score`）/
   立直后和了率（`riichi_win_rate`）六个的 Δ + CI，外加 `quality`（**新规则**：越界 ⇔
   `CI 上界 < 0` **或** `点估计 < −tol`，`tol = 2.0pp`）；`decline_rate` 与 `dama_rate` 也一并贴。
④ **止损**：任一伴随量按新规则判越界 ⇒ **立即结案**并按"走偏"写结论（不再烧算力）。
