## 0. 一句话

上一轮的结论**不成立为"奖励不能改变方向"**，而是两条测量缺陷：
① **尺度错**：`w=2` 的塑形只有结果奖励的 **0.036%**（1:1 需 `w≈2782`）⇒ 那个 `w` 下机制上几乎无效应；
② **n=1/臂**：两臂各只跑一条链，训练侧噪声（几个顺位点）盖过要测的效应。
本实验把这两点同时修掉：**三档 `w` × 每档 2 条独立链 × 2 代**，加上**臂对臂**直接对打（不受现任漂移混杂）。

⛔ 这不是判决：判决仍只看 `mahjong_ml/v4/gate.py`。本实验的产物是**剂量-反应读数 + 臂对臂配对读数**。

## 1. 校准：`w_for_parity` 的**实测值**（跑链之前先量）

**探针**（与六条链**完全同配方**，只有场次少）：`v4 loop --games 400 --max-steps 20`，
`MAHJONG_STYLE_BONUS='riichi=2.0:no_deal'`，起点 = `tools\build\v4-expert-defrep-g10\net.bin`，
风格桌（本线 `def` + `atk`/`win` 各 1 席）。日志原文（`w-ladder/_probe-loop.log`）：

```
  轴 riichi     w=2  成对质量轴=no_deal  μ=0.277426  σ=0.447729  付奖小局 1128  付奖总额 +431.2
  风格奖励塑形：`style_bonus` 列覆盖 266843/266843 行（非 0 = 那一小局被付奖）；小局级 mean -0.1
  std 1.9 **点** vs 结果奖励 std 5351.5 点 ⇒ **0.00036× 结果奖励的尺度**（= 「这一轴会不会支配梯度」的
  **尺度**读数：远小于 1 就推不动；要 1:1 大约要 `w=2782`）
```

⇒ **实测 `w_for_parity = 2782`**（与任务给的 `≈2600` 同一量级；比它高 7%）。

**独立复核（第二套算法）**：白化后的列只有两个取值 —— 付奖（`riichi ∧ no_deal`）时 `w(1−μ)/σ`、
否则 `−wμ/σ` ⇒ `std = (w/σ)·√(p(1−p))`，`p = 1128/4585 = 0.24602` ⇒ `std = 1.92385`（打印四舍五入成
`1.9`）⇒ `w_for_parity = 5351.5/1.92385 = 2781.7`。**与日志的 2782 逐位一致**（两条独立算法互证）。
第三套：拿上一轮 1000 场的 `v4-sty-a-g01` 轨迹（同一配方、同一学生）现算 μ=0.282717、σ=0.450320 ⇒
预测 2748 —— 三套读数落在 2748~2782（±0.6% 以内）。

### ⚠ 一条必须写在本节的口径注记（本轮发现的**读数缺陷**，不是改判据）

那一行打印的是「把**当前这笔**塑形放大的倍数」（= `base_std / std(塑形列)`），**不是"该设的 `w`"**：
`std(塑形列) = w · std(z)` ⇒ `打印值 = base_std/(w·std(z)) = w*_1to1 / w`。
于是 **`w=2782` 时塑形 std = 结果奖励 std 的 0.5×（方差 0.25×）**；真正的 std 1:1 需要
`w* = w × 打印值 = 2 × 2782 ≈ 5560`。因此本实验按**任务口径**（读打印值取整）取 `w_top`，
并把它**明确记成"打印视差档"**，`w≈5600` 写进 §4 的"下一步"。

### 最终三档（本实验的自变量）

| 臂 | `--style-bonus` | 相对打印视差 | 相对结果奖励的 **std** 比（预期） |
| --- | --- | ---: | ---: |
| **`w=0`（对照）** | **空串**（= 不传这个参数，功能关闭） | 0 | 0 |
| **`w=300`** | `riichi=300:no_deal` | 10.8% | ≈ 0.054× |
| **`w=2800`** | `riichi=2800:no_deal` | 100.6%（打印视差） | ≈ 0.50× |

* 为什么 `w_top=2800` 而不是 2782：**就近取整到百位**（差 0.6%，对"尺度对不对"这个问题毫无影响，
  但让"这一档是打印视差"一眼可读）。
* 为什么 `w=0` 臂用**空串**而不是 `riichi=0:no_deal`：空串 = 那个功能**不存在**（不建列、命令行
  逐字不变）⇒ 它与上一轮的对照臂 `v4-sty-a` **逐字同配方**，才能拿来做"同配方第 2/3 次跑"的噪声地板
  读数（§5）。`riichi=0:...` 会建一列全 0，**多一个变量**（列存在本身要过断言），不必要。
* 为什么中间档取 300（而不是 100/1000）：它是 `w_top` 的 ~10%，三档的目的**只是看单调性**
  （两档只能看"有没有差"，三档才能看"是不是随 `w` 单调"）。

## 4. 读数与判据（**跑之前**就写好；"看到什么算什么"）

### ① 主判据 = **剂量-反应（单调性）**

`tools/style-vector.py`（**判据侧的独立实现**，⛔ 不自己算风格量）读每代采集轨迹的 **`riichi_rate`**：

* **信号**：三条臂的**臂均值**（每条链代 2 的读数取臂内均值）随 `w` **单调↑**，且**极差量级**
  满足 `mean(w=2800) > mean(w=300) > mean(w=0)`；
* **辅助（更强）**：**臂间区间不相交**更好 —— 即 `w=2800` 两条链的 `[min,max]` 与 `w=0` 两条链的
  `[min,max]` **不重叠**；
* **噪声参照**：§5 的同配方三次跑给出"同一个 `w` 下换 seed 能差多少"；
* ⛔ **不用单链 vs 现任的差当结论**（上一轮的教训）；单链读数只作描述。

### ② 臂对臂直接对打（**不受现任漂移混杂**的问法）

`w=2800` 的两条链 × `w=0` 的两条链 = **4 组配对**（2×2 全配），每组：

```
python -m mahjong_ml.v4.gate --incumbent <w=0 链> --candidate <w=2800 链> \
    --seeds 77760001,77760002 --games 3000 --block 3000 --workers 12 --line def
```

* **主口径** = `deals`（`def` 线；已取负 ⇒ 正 = 候选更好）；**护栏** = `rank_points`，**CI 下界 ≥ −1.0**；
* 每组给**逐套 + 合并**读数；四组一起看**符号一致性**（4/4 同号才算稳）；
* 牌山刻意取**上一轮终点判决用过的那两个**（同一批 ⇒ 可与上一轮的读数交叉比对；
  这两个 seed 与六条链的采集 seed 都不相交）。

### ③ 护栏

任一臂对臂配对的 `rank_points` CI 下界 **< −1.0** ⇒ 记"为了风格换了强度"（负结果，按 §5 的分支读）。

### ④ 失败分支（**预先写明**："如果 `w=2800` 都推不动立直率"意味着什么）

| 观测 | 含义 | 下一步 |
| --- | --- | --- |
| 立直率随 `w` 单调↑，且 `w=2800` 臂 vs `w=0` 臂 4/4 组同号为正 | **奖励能主动改变训练方向**；剂量-反应成立 | 找**代价**（护栏 + 逐维读数）；再把同一通道接到别轴（`meld` / `默听`）；若要更细，把塑形挂到**逐决策**的潜在量上 |
| 立直率↑ 但护栏破（`rank_points` CI 下界 < −1.0） | 方向能推，**代价是强度** | 降档（回到 300 或取 1000）；把质量轴从 `no_deal` 换更严的 `win`；或把塑形只加在学生行 |
| **三档臂均值都落在 §5 的噪声地板内**（推不动） | 两种可能，必须分开说：**(a) 尺度仍不对**（`w=2800` 名义 1:1，但按 §1 的口径注记其实只有 0.5× std、0.25× 方差 ⇒ 下一档该上 `w≈5600`）；**(b) 这一轴对奖励不敏感**（小局级常数奖励没有信用分配，"在哪一手立直"拿不到梯度） | 先看每代日志的**尺度读数**（`hand_std_vs_reward`）：若已 ~0.5 而仍无位移 ⇒ 走 (b)：改**逐决策**塑形（PBRS/潜在量）或换更密的轴（`meld`）；若读数远小于 0.5 ⇒ 走 (a)：加倍 `w` |
| 立直率↑ 但**副露率/和了率/放铳率同时劣化** | 奖励在换别的维度，不是白拿 | 记代价，按"质量轴加严"处理 |
| 三档之间**非单调**（如 300 > 2800） | 要么剂量太大把策略推离，要么噪声地板 > 效应 | 读臂间区间与 §5；结论按"这一档 `w` 内看不出单调"写 |

## 5. 噪声地板（第二个独立样本，直接关系到 `def7` 的 `+3.69` 可信度）

上一轮报告 §4 的原话是"**`n=1/臂` 的 A/B 对比没有信息量，连点对点的'单链累积'结论也要重复才敢信
（`def7` 那个 `+3.69` 目前只有一条链）**"。本实验的 `w=0` 两条链**与上一轮的 `v4-sty-a` 逐字同配方**
⇒ 三条链（种子各不相同）给出"同配方换 seed"的**第二个独立样本**：

* 读数：三次跑的**逐代** `riichi_rate` / `副露率` / `和了率` / `放铳率` / 采集顺位点（含**逐场 SE**）；
* 判据：三次跑的**极差**就是"训练噪声地板"的一个直接估计（对照 §4 ① 要测的效应量）；
* 对 `def7` 的意义：若这个地板 ≈ 3 顺位点或更大，那么"单链 `+3.69`"**至少有一部分是噪声**，
  需要多链重复才能当采纳证据 —— 这条**不影响** `def7` 已有那条 6 套 × 6,000 场的闸门读数
  （那是配对判决），但**确实**说明"同配方换 seed 的链间散布"与"闸门分辨率"是两件事，不能互相替代。
