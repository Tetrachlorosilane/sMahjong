# 预注册模板（新风格轴 / 新口径）：六条流程判据

> 用法：复制本文件为 `PREREGISTRATION-<轴名>.md`，在 §1 之前把下面各条逐条落成可执行的判据（含命令与期望输出）。
> 来源：`fold` 轴那一轮（`PREREGISTRATION-FOLD.md` §6.1）踩出来的三条 + 第四条的授权改写 + `pon` 轴加的第五条
> + BL-03 加的第六条（ceiling 硬前置）。

1. **口径冒烟测试（跑链之前，≤50 场，强制）**：新轴的第一件事不是跑 1000 场，而是在 ≤50 场小样本上把
   **奖励侧集合 == 判据侧集合**逐项验一遍（分子 / 分母 / 付奖 / 拦下 / 取不到，逐键相等）。
   ⛔ "看起来差不多"不算，"命令行一样所以口径一样"也不算；⛔ 不许留到跑完再回头查 —— `fold` 就是这里错了三轮、墙钟从 110 min 涨到 195 min。
2. **门槛与主判据同口径**：付奖行率之类的门槛必须用**与主判据同一口径**的数判（`fold` 实测：学生席 `1795/172698 = 1.0394%` 过线 vs 四席 `7216/695088 = 1.0381%`；
   历史上出现过四席 1.186% 过线 / 学生席 0.9891% 不过线 ⇒ **结论会翻转**）。⛔ 不许一个口径过门槛、另一个口径出主读数。
3. **对账基准必须同版代码**：基准只能是**当前奖励代码在同一份轨迹上重算的账**；冻结的 `audit/<tag>.json` 是**训练当时**那版代码的产物，
   落后就**照实报差异**（`fold`：`threat +4892 / fold +96 / push +4796`，逐位解释见 `_fold-selfriichi-probe.py`）。⛔ 不静默抹平、不拿它当基准、也不删它。
4. **逃生阈值（改写）**：⚠ 旧判据"端到端重采 > 5 min ⇒ 停下报告"**作废**；新判据 = **成本 ≤ 10 min 且操作确定性 + 可自证 ⇒ 可执行，但必须在报告与 `NOTES.md` 里记下这次偏离**
   （自证 = 逐场 `seed`/学生席不一致 **0** + 与冻结账**逐项**对账相等 + 重采命令行与冻结日志 `[cmd]` 行**逐字相同**）。
   ⚠ 推论：读数路径（`post --reuse`）自己坏了属于**阻断项**，修它同样要记偏离，⛔ 不许拿"手搓一份读数"绕过它。
5. **伴随质量量的越界判据必须按「轴的意图」定方向**（`bad_when`；2026-10-11 加，`pon` 轴 n=2 那一批）：
   越界 ⇔ **在坏方向上显著**（**按符号取单侧 CI**）**或** 点估计**越过该方向的容忍带**。
   - **坏方向由轴的意图定，⛔ 不由统计量定**：`down`（越多越好）= 和了率 / 副露率 / 立直率 / 打点 /
     立直后和了率，以及**各轴自己的目标量**（默听率 / 能立而不立 / 降り率 / 碰取向 —— 付钱就是要把它们推上去）；
     `up`（越少越好）= **放铳率**、被自摸、巡目（早立直轴：巡目上升才是坏）。
     `down` ⇒ 越界 ⇔ `hi < 0` **或** `Δ < −tol`；`up` ⇒ 越界 ⇔ `lo > 0` **或** `Δ > +tol`。
   - ⛔ **为什么方向必须按轴意图定**：这条判据问的是「**这笔钱是不是买到了效果却付出了代价**」，而**代价是
     有符号的** —— 同一个 Δ=−0.99pp，落在"要和了率"上是要买的（坏），落在"放铳率"上是白赚的（好）。
     **方向无关**的规则（旧版：只看 `hi < 0`）等于**把"变好"也判成越界** ⇒ 任何**同时改善防守**的轴都会被
     误杀，判据会把正确方向的动作淘汰掉。实测：`pon` 轴 c1 的放铳率 Δ=−0.992（上界 −0.136，
     **放铳变少 = 有利**）被旧规则误报成越界。
   - **容忍带随单位走**：`avg_win_score` 的单位是**点**（≈7000），⛔ 不许套 `±2.0pp`
     —— 套上去会把 Δ=−26.19 点（CI 含 0）误判成越界（`W-REPORT-DAMA-N2.md` §3 踩过）。
     口径 = **闸门侧同量纲**（`win_points:150`）⇒ 打点用 **150 点**。
   - **实现只许一处**（`tools/w-ladder.py` 的 `companion_verdict` + `COMPANION_BAD_WHEN` /
     `COMPANION_TOL_BY_METRIC`）；⛔ 表里查不到方向的量**当场报错**（不给"缺省向下"的静默兜底 ——
     兜错方向判据就是反的、还看不出来）。判据侧脚本**import** 它，⛔ 不抄第二份公式。
    - **回归判据**：`down` 类量走的是与新规则**逐字相同**的式子 ⇒ 既有产物必须**逐字节不变**
      （对拍法：`git show HEAD:tools/w-ladder.py` 现取旧版 → 同一份 `paired/*.json` 两边各跑一次
      `quality` → 比 `--out` 文件字节）。
6. **新臂先过 ceiling 闸门（硬前置；2026-10-12 加，`BACKLOG.md` BL-03）**：任何新臂**在投训练之前**必须先过 ceiling 闸门
   —— **墙钟 ≤30 min 且零训练进程**：`python tools\ceiling-gate.py --collect --tag <标签> --wall <族 seed> … --games ≤1000 --base-net <现任> --cand-net <新臂> --table <三个对手 net>`（接口/字段/判据见 `tools\AUTOMATION.md` §7；也可 `--gate-dir`/`--family` 零采集复算）。
   **未过或测不出 ⇒ 不许开训**：只有 `verdict.json` 的 `verdict == "过"`（退出码 0）才放行，`不过`/`测不出`/`ERROR` 一律停下先报。
