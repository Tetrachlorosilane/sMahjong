## 3. ⛔⚠ 第二个坑：**冻结审计账与 HEAD 的奖励代码不一致**

`audit/v4-wl-fold-c1-g01.json` 给 **35828/1891/33937**（付奖 1578 / 拦下 313），
差 **+4892 / +96 / +4796**（付奖 +90 / 拦下 +6）。**逐位解释**（`_fold-selfriichi-probe.py`）：

```
① 学生出牌行里「自己立直 ∧ 别家都没立直」            = 4892  == Δthreat
②a 其中"打出的牌对自己也是現物"                      =  287
②b 自己与别家都立直、对别家現物但对自己不是現物      =  191
⇒ Δfold = ②a − ②b = 96  == Δfold（吻合）；Δpush = 4892 − 96 = 4796（吻合）
```
⇒ 冻结账是**训练当时那一版** `threat_seats(obs)`（**不带 seat**，把"行动者自己已立直"也算被威胁）
的产物；HEAD 的代码只数别家。**所以**：① 冻结账不能拿来对 HEAD 的判据侧（那样只会得到一个与代码
无关的"对不上"）；② 对账基准换成 `_reward_fold_account`（当前奖励代码在同一份轨迹上重算），
与冻结账的差**照实报出来**；③ 本轮链实际付出去的是**字面口径**（多付 96/1795 = 5.3% 的付奖行）。

### 5.2 一代功效估算（回答"要几条链"）

- 训练前逐场 `fold_rate`：均值 **5.588%**、sd **4.487%**（每场 降り 1.79 行 / 被威胁 30.9 行）。

  （和了率 0.785 / 放铳率 0.875 / 打点 0.830）折算 ⇒ **一代配对 SE ≈ 0.118% ≈ 0.12pp**。

- ⚠ 读法：这个轴**不属于**"1 代 × 1000 场测不动"那一类（预注册 §4 的第一种结果的前提不成立）；
  本轮缺的是**数据**（补采轨迹被删），不是**功效**。⚠ 配对效率是**借**另外三个量估的

## 6. 两条流程判据（已写进 `PREREGISTRATION-FOLD.md` §6.1 / `NOTES.md` §6.5 末尾）

1. **口径冒烟测试（跑链之前，强制）**：新轴开跑前先在 **≤50 场**上把"奖励侧集合 == 判据侧集合"
   逐项验一遍（同一份轨迹、两侧各自实现、五个数 + `mu` 全等）。上一轮这里错了三轮 ⇒ 墙钟
   **110 → 195 min**。本轮 30 场就一次定出真分歧（总体），并把误诊当场否掉。
2. **门槛判据必须同口径**：1%/行 的门槛必须用**与主判据同一口径**的数判（同一份数据：学生席
   **1.0394%** vs 四席 **1.0381%**；历史上一轮 **四席 1.186% 过线 / 学生席 0.9891% 不过线**
   ⇒ 结论会翻转）；且**对账基准必须与判据侧同一版代码**（冻结账会随代码改动过期）。

## 7. 下一步的改动点与成本（⛔ 本轮不加链、不跑闸门）

优先级 1 = **安全口径改为"对至少一家安全"**（普查实测 **8.62%/行** vs 现值 **1.04%/行** ⇒
付奖行率约 ×8）：成本 = 两侧 `fold_row_ok` 各改一处 + 重跑 `_verify_fold_totals` + 重跑**一条链**
（12.8 min/代）+ 重算剂量（`μ` 变了）。
优先级 2 = **威胁集扩到 T1∪T2**：⚠ **必须改付奖行定义**（`threat_seats` + 口径句 + 判据侧同步），
才有用；⛔ **只把 T2（= 出牌行的 10.80%）加进分母/进度量只会稀释**（分子不变、`μ` 变小 ⇒
付奥行率与信噪比一起降）⇒ 成本同上再 + 重新校准剂量与重测分档。
