# 预注册（设计 + 判据）：P2-11「共享主干 + 域条件化分叉」
> **写在跑之前，跑之前不许改**。⛔ **本文件只是设计 + 预注册：不跑训练 / 不跑采集 / 不跑闸门**（含 §4 的训前 ceiling 闸门 —— 只写方案，不执行）。
> 依据 = **实验 A 定论**（`EXPERIMENT-A-DIVERGENCE.md`；复核见 `IDEAS-COMPLEMENTARY-AND-ARCH.md` §4.1）：D 上样本外路由增益 **+29.23 点/小局（SE 29.79，t=0.98，CI[−29.15,+87.61]）含 0**；机制 = **769/1000 场在「第 0 小局内」一次性分岔**、真·同状态小局仅 **2.5%** ⇒ 之后两条轨迹互不相干 ⇒ 按结果后验选臂**注定是均值回归**。
## 1 判据来源（实验 A 的设计结论；⛔ 不许重开这一条）
- **互补的充分条件 = 两臂行为相同直到某个「可辨状态」，然后在该域上刻意分歧**（= 在**同一状态**上分叉，而不是两条各自漂移的轨迹）。
- ⛔ **"两个独立训练出来的网"整族已被否掉**（P2-01/03/12/14/16 那类）：独立两网**第 0 小局即分岔**；¬D ∧ 前缀干净（n=288）时两臂账**逐位相同 ⇒ 神谕恒 0**。
- ✅ **唯一未被否掉的形态 = 共享主干 + 域条件化分叉**：对应 P2-11 目标条件化单网（style token，主）/ P2-05 域独占训练 / P2-10 同状态反事实专家。
- ⚠ **别混**：被否的是「阶段 4 事后按桶选现有专家」与「独立两网 + 结果侧路由」，⛔ **不是** MoE 联合训练本身。**判据句**：多专家路线的闸门 = 两臂必须"同到可辨状态再分歧"。
## 2 最小方案（3 个候选实现；每条写清"为什么满足同到可辨状态再分歧"）
- **a. 单网共享 trunk + 域头/域门控**（域 = **完全公开状态**，如 `obs.kind` / 别家 `obs.riichi` / 巡目桶）：**同一份主干、同一份权重、同一个状态**，输出差**只**来自那一维公开域量 ⇒ 域量相同处两臂**逐位同源**，分歧是「可辨状态的函数」而非轨迹漂移。
- **b. 共享前缀 warm start + 域限制微调**（P2-05）：两臂**同起点同权重**，`loss` **只在 D 的行上回传**、D 外梯度掩码为 0 ⇒ D 外**逐位相同**（不含 D 的行永不更新）⇒ 分歧被钉在 D 内，D 就是那个"可辨状态"。
- **c. 共享 trunk + 域条件化 reward**（P2-10 同状态反事实）：同一网、同一批**同状态**数据，只有 D 内的奖励项/目标切换 ⇒ "同状态反事实对"**天然满足**判据（对比发生在**一个状态内部**）。
## 3 域候选（必须**完全公开可辨**；覆盖率给量级，实测数引 `AXIS-CENSUS.md`）
- **动作段（`obs.kind`）**：`turn` **78.82%** / `claim` **21.18%**（134,779 + 36,215 = **170,994** 学生席决策行；**精确**计数）。
- **被威胁（别家已立直，`obs.riichi`）**：`A_threat_discard` **26,170 = 15.305%** 决策行（**精确**）；该层两臂分歧率 **17.06% vs 无 11.76%**（实验 A §3）。
- **序盘 / 终盘（巡目 `obs.player_draws`）**：量级 **30~45%**（≤6 巡）/ **≤25%**（≥13 巡）—— ⚠ **估**（自家回合行 134.8 行/场/席、11.28 小局/场）⇒ 待 `axis-census.py` 加一档**实量**（与现有四列表同一份轨迹，零额外采集）。
- **点棒 / 顺位状况（`obs.scores` / `obs.round`）**：**每行都有（覆盖 100%）**但**桶间极不均衡**；桶必须先写死（如 `scores[自己] < 20000 / 20000~30000 / >30000`）并量桶覆盖率，⛔ 不许事后拣桶。
## 4 判据（训前**便宜闸门** + 正式判据）
- **训前（复用 ceiling 方法论）**：在域 D 内**逐小局取最好臂**（**状态限制神谕**）+ **均值回归检查** `ρ(Δ神谕, 现任自身得分)`。PASS = `ceiling_D` 点估计 **> 0** **且 t > 2** **且 |ρ| < 0.25**（全局那次 = +36.7 点/小局、SE 26.22、**CI 含 0**、`ρ = −0.531`）。⛔ **不用分类器**：实验 A 已证"用公开特征预测哪一臂更好"这条路无效。
- **正式**：共享 seed **逐场配对** Δ/SE/CI（自证 `seed 不一致 0 · 学生席不一致 0`），且**与"最好的单臂"比**（⛔ 不与现任比）。两条件缺一不可：(a) Δ 对最好单臂的 **CI 下界 > 0**；(b) **机械自证 D 外两臂逐位相同**（与实验 A 的"¬D ∧ 前缀干净 ⇒ 账逐位相同"同型）。
## 5 成本估算（实测口径；⚠ **降载后墙钟未知**，按更慢估）
- 按实测：**1 臂 1,000 场 ≈ 208 s**、**一条 4 代链 ≈ 12 min**、**闸门 12,000 场 ≈ 36–45 min**；五臂共同评测（ceiling 口径，**逐手轨迹已删 ⇒ 必须重采**）实测 **1506.8 s**。
- ⇒ 最小判据 ≈ 训前 ceiling **~25 min** + 2 臂 ×（1 代 × 1,000 场 ≈ **12 min**）+ 闸门 **~40 min** ≈ **~90 min**（**降载前**）。⚠ **降载后墙钟未知**（`--workers` 6 而非 12 ⇒ 只会更慢），⛔ 不许拿 90 min 当承诺。
## 6 止损（什么结果判"这条路也不通"）
- **训前**：任一候选域的 `ceiling_D` **CI 含 0** / `t ≤ 2` / `|ρ| ≥ 0.25` ⇒ 该域**不通**，⛔ **不训**（= 旧 NO-GO 在域内的重演）。
- **训后（机械）**：D 外"逐位相同"自证**失败** ⇒ 判「实现没做到同到可辨状态再分歧」，该轮**作废**，⛔ 不加域、不加代。
- **正式**：Δ 对最好单臂 **CI 含 0**，且**所有**候选域皆然 ⇒ 判「**共享主干 + 域条件化也不通**」= **多专家路线整族封存**（与实验 A 同结论，⛔ 不再换第三种形态）。
