## 0. 剂量换算算法（唯一的新参数）

1. **同权点 `w*` 的定义（逐行方差同权）**：`decision` 模式下只有**真的执行了该动作**的行非 0
   （`style_reward` 的行级付奖）⇒ 「塑形列 std `Y` == **纯结果奖励** std `δ`」= 1:1。
   而**被减奖励**（含塑形列本身）std `Z` 满足 `Z² = δ² + Y²` ⇒ 同权点等价于 **`Y/Z = 1/√2`**
   （⚠ 这就是 `W-REPORT-MELD.md` §1 说的"逐行比值的上确界是 1/√2"：`decision` 口径下可达的
   比值是 `Y/Z`，`Y/Z = 1` 达不到；`Y/Z = 1/√2` ⟺ `Y = δ` ⟺ 方差同权）。
2. **`parity_note()` 的线性外推**（`style_reward.parity_note` 的第二条读数 = 真正进梯度的行）：
   `w = 1000` 时 `Y/Z = 0.165`（`Y=869.5` / `Z=5263.7`，`CALIBRATION-MELD-raw.txt`）
   ⇒ `w* = 1000 / 0.165 ≈ 6060`（上轮选定值，`PREREGISTRATION-MELD.md` **D4**）。
3. **独立复核（上轮 `meld-dose-check.py` 的自证表）**：`w = 6060` 时 `Y/δ = 0.986~1.048`
   （反推同权 `w` = 5,784~6,147）⇒ 与 6060 同点。**两条独立读法落在同一点** ⇒ `w* = 6060`。
4. **本任务的两档低剂量 = `w*` 的固定分数**（比例线性：`Y ∝ w`）：
   - 低档 = **0.25 × 6060 = 1515**（任务里的 `meld≈1500`）
   - 中低档 = **0.50 × 6060 = 3030**（任务里的 `meld≈3000`）
   ⛔ 不用 `parity_note` 打印的 `17381`（那是**小局级**读数的外推，`decision` 模式下失真，见 D4）。

## 2. 判据（先写死）

- **① 位移—剂量**：两档 `post`（末代权重、**同 seed 逐场配对**）的**副露率 Δ + CI**，
  与 `meld=6060` 的 `c1 +27.80pp` / `c2 +15.41pp` 并排 ⇒ 判**单调性**与**边际收益**（每 +1000 剂量换多少 pp）。
  （门槛沿用 `PREREGISTRATION-MELD.md` §1：Δ ≥ +2pp 且 CI 排除 0。）
- **② 代价—剂量（核心）**：两档的 **和了率 / 放铳率 / 平均打点 / 采集顺位点** 配对 Δ + CI；
  `wins` 护栏**同量纲换算**：`Δ(每场每席和了次数) = Δ(和了率 pp)/100 × 每场每席小局数`，
  容忍带 **0.10/场/席**（`PREREGISTRATION-MELD.md` §3 护栏 `wins`（0.10））。
- **③ 稳定性**：与上轮 c2（+15.41pp 且几乎免费）比 ⇒ "免费位移"是**剂量低就能稳定拿到**，还是**链间运气**。
- **④ 轨迹侧伴随量**：`tools/w-ladder.py quality --metric win_rate`（缺省口径必须与
  `companion-quality.json` **逐位相同**），逐档给 `ok/exit`（0 = 不越界、3 = 越界）。
- **止损**：任一档出现「伴随量显著退化」⇒ **立即停并结案**（判据 = 轨迹侧 `win_rate` 单侧越界
  （CI 下界 < −2.0pp）**或** `wins` 护栏同量纲 Δ ≤ −0.10/场/席），不再烧剩余算力。
