## 3 判决（可证伪性成立）

1. **真的出局了一条**（不是"全过"）：`E1 hand_agg` / `E1 winner_delta` / `E3 hand_norm` / `E2 dealin_sum` /
   两条阴性对照**逐条出局**，其中 NEG 两条**按跑前预期**出局 ✅ ⇒ 判据没放水。
2. **唯一"合法上限真升高且本表示上可学"的候选 = `E1 own_win`**（×2.10）。其余"可用"的四条全是
   **恒等式/同源**（`ctx` 里已有当前点数，或与 `effect` 同源）⇒ ⛔ 不构成"目标可学"的证据。
3. **E2 辅助重加权整族不可用**（预算内免探针论证，逐头实测）：`placement` 合法列 R² 0.3236 ≈ 自身 0.3183
   （上限=自身）· `shanten` 1.0000（与 `effect` 同源）· `danger` 合法列 R² **−0.0073**（信息不在）；
  并且它们**都不在推理路径上**（`model.py:56/61` `contract=False`）⇒ **重配权不改任何信息上限**。
4. **E3 整族不可用**：`hand_norm` 合法列 R² **0.0488 < 0.0664**（上限反降）；`--rank-weight` / 归一化尺度
   都在 **`pretrain.py:353` 的学生行优势归一化**之后被消掉 ⇒ 结构上不改可学份额。
5. ⚠ **本批最重要的发现（可行动的缺口）**：**"自家和了打点"这一列在紧凑集里根本不存在**
   （`aux_win_flag` 只有二值核、`delta` 是含立直棒的收支、`value` 是整场终值）⇒ 真正的"自家手牌价值"
   目标**必须先扩数据**。所以本批**筛出的东西是"该扩哪一列"**，而不是"该开哪条臂"。
