## 0 唯一自变量 = **数据新鲜度**（等算力约束下）

| | **臂 A（新鲜 · 多轮短采）** | **臂 B（冻结 · 少轮长训）** |
|---|---|---|
| 采集 | k 轮 × 1,000 场，**每轮用当时 θ_i 现采**（`net:<θ_i>@0#0.5`） | **一次** 6,000 场，全程同一 θ_0 |
| 训练 | 每轮在其**新数据**上训 100 步 ⇒ θ_{i+1} | 在该**冻结**数据集上连训 600 步（6 段 × 100 步，`--save-optimizer`/`--resume-optimizer` 保留动量） |
| 轮/段间 | BL-14 的 `pair --rounds` 重叠：`train(D_i,θ_i) ‖ collect(D_{i+1},θ_i)` | 段边界 = `--stop-after-steps` 100/200…600（同 epoch 内 ∧ `opt.step()` 边界 ∧ 正常收尾） |
| θ_0 | 两臂**同一**起点网 `tools/build/v4-expert-defrep-g10/net.bin`（sha256 `167a7002…87df`） | 同左 |

**等算力口径（预注册）**：① **总采集场数相等** = 6,000 场/臂；② **总训练步数相等** = 600 步/臂（6×100）；
③ **总墙钟相等（±10%）**；④ 两臂报**实际**墙钟 / 场数 / 步数，偏差 >10% ⇒ 重算判据或标「不等算力」。
起点 + 终点（导出 net.bin）都算进墙钟。

## 1 判据（预注册写死 · 逐条贴原始输出）

## 2 四种结果的解释（跑前写死，避免事后挑口径）

- **A 显著更强**（CI 排除 0 且为正 ∧ 逐族同号 ∧ BonfCI 排除 0）⇒ **新鲜度胜**：等算力下「勤采」优于「囤数据」。
- **无差异**（CI 含 0）⇒ **等算力下新鲜度不是瓶颈**：该分辨率测不出差别，报 MDE 与所需 N。
- **B 显著更强**（Δ(A−B) CI 排除 0 且为负）⇒ **数据量胜**：冻结数据上多训更划算。
- **测不出**（护栏破 / 合规链断 / 族间异号 / 臂 B 长训被 KL 早停截断到不可比）⇒ 报 MDE、断在哪、需要多少 N。
