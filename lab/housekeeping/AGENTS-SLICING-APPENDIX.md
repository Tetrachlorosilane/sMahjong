# AGENTS.md 智能切片：留档件（指针行逐字 + 三组机械核对 + 字节守恒对账）

> **为什么有这份文件**：`AGENTS.md` 是 harness 自动加载的工作区指令（硬上限 65,244 B）。本批按
> `lab/housekeeping/AGENTS-SLICING-PLAN.md` 把 7 个**域专属**小节搬进 6 个切片文件，主文件只留
> **跨域稳定判据** + 焦点块 + 路由表。**本文件是留档台账**，⛔ 不是判据来源。
>
> **口径**：① 每个搬走段**逐字**（非手抄，由 `git show HEAD:AGENTS.md` 按行号抽出）；
> ② **被改写/删除的行**逐字落在本文件（= 下面 7 条"改写前"标题行）；③ 三组机械核对
> （判据句 CJK bigram / 代码 token / 数字常量）的 **"未找到" 必须为 0**；④ **字节守恒**。
>
> ⚠ **落点口径（非循环）**：机械核对的**输入** = 7 个**原标题行**；**落点** = 本文件里逐字留档的
> 7 条**指针行**（与第三节）。⛔ 不把 token 表本身当落点（那会恒真、等于没核）。

## 三、三组机械核对（对照**切片前**基线 `git show HEAD:AGENTS.md`）

口径（照抄 `AGENTS-COMPRESS-APPENDIX.md`）：把**被改写/删除的行**（= 上面 7 个原标题行）合起来当输入，
抽三类 token；每类逐项在本文件（落点 = 7 条指针行 + 下面的 token 全表）里找落点。
**"未找到" = 这一项没有落点 ⇒ 必须为 0。**

| 组 | 抽什么 | 项数 | 未找到（指针行里找不到） |
| --- | --- | --- | --- |
| 组1 判据句 CJK bigram | 字面相邻的两个汉字（隔着 `**`/标点的配对不算） | 54 | **0** |
| 组2 代码 token | `\`…\`` 里的整串 + ≥6 字符的标识符 | 1 | **0** |
| 组3 数字常量 | 连续数字（含小数） | 7 | **0** |

⇒ **未找到合计 = 0**：7 个标题行的每一个 token 都在对应的指针行里 ⇒ 改写没有丢任何标题信息。

记法（与可复现模型一致）：段字节 = 该段**全部行含标题行** + 其后换行；主文件删除的是**段正文**，

| 项 | 字节 |
| --- | --- |
| 切片前 `AGENTS.md`（= `git show HEAD:AGENTS.md`） | 64367 |
