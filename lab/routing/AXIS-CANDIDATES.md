## 0. 三条硬判据（三轮实测换来的，⛔ 先过筛再谈实现）

1. **付奖的那一行必须是"真动作行"**：能对应一个**重复发生、频率不低**的选择（立直/鸣牌/打牌/见逃）。
   ⛔ 反例 = `win`（和了率）：`tsumo/ron` 几乎必然 ⇒ 用行级奖励推它 = **对结果重复加权**（实测把和了率推成 −1.02pp、立直率 −1.60pp）。
2. **伴随质量量必须"对该行不空转"**：⛔ 反例 = `win` 轴的 `no_deal`（和了者天然未放铳 ⇒ 恒真 ⇒ 付奖 2230/2230、别无条件可拦）。
   ✅ 正例 = `riichi` / `meld` / `dama`：付奖行是**宣言/鸣牌行**，`no_deal` 是真门。
3. **可独立测量 + 可配对**：判据侧要能在 `style-vector.py` 里独立实现（分子/分母写清），并能做**同 seed 逐场配对** ⇒ 否则只是"贴标签读数"，不是证据。

## 3. 推荐的三条参考路线（自主排序）

**路线 1（先做，最便宜且信息量最大）：`立直巡目`（B）+ `副露种类`（D）**
理由：两者都**几乎零实现成本**（轨迹里全有），与已实现的 riichi/meld **正交**（同样频率、不同取向），
且伴随量都是真门（`no_deal`）⇒ 可直接复用现成的 `probe → post → 配对 → quality` 流水线（≈25 min/探针）。
⇒ 一次就能回答"同一决策点的**时机/方式**维度能不能被奖励推动"，为后续所有轴立模板。

**路线 2（价值最高，成本中等）：`押し率/降り率`（A）**
理由：这是立直麻将**理论上的核心维度**（押し引き），现有三轴完全没覆盖；频率高、与现有轴正交。
代价：要在轨迹侧引入"被威胁"与**危险度**（引擎已有 `Danger`，需确认能否从合法观测里取到——⛔ 不能用隐藏信息，
否则训练会作弊）；先做**可测性普查**（见 §4）再实现。

**路线 3（战略级，先别急）：`局面依存押し引き`（K）**
理由：实战价值最高（顺位/点棒改变打法），但它是**建立在 A 之上的条件化轴**，且判据必须控制混杂
（"顺位差"本身与牌山运气相关）⇒ 等 A 站住、且我们有了"多链 + 臂对臂"的协议之后再上。

## 4. ⛔ 实现任何轴之前先做**一次普查**（≈12 min，1×1000 场）

现在还没有任何一条轴做过"频率 × 可识别性"的台账。一次采集（现有 `probe` 即可）就能同时量出**全部候选**的：
`每席每局出现次数`、`占决策行比例`、`能否唯一落行（付奖行 == 该定义的行数）`、`伴随量是否恒真`。
判据：**频率 <1%/行 ⇒ 不值得做成轴**（噪声地板会吃掉它，就像双响那 0.27% 差点把 `win` 轴判死）。

---

## 5. 与"QD / 风格谱"的关系

风格 = **向量**；QD 归档要求**格间差 > 链间噪声**（实测 meld 同剂量链间散布 **7.43pp** ⇒ 每格 ≥2 链）。
⇒ 轴的**选择**比轴的**数量**重要：应挑**低方差、高频率、正交**的量（立直巡目/副露种类这类计数轴），
而不是高方差量（打点）。**打点只当伴随量/代价量，不当主判据。**

## 6. 威胁来源分档 T1/T2/T3（`fold` 轴 · 2026-10-11 实测）

- **T1** = 至少一家处于**立直状态**（`obs.riichi`，⛔ 不含自己已立直的行）⇒ 唯一有权威公开读数的档（付奖行**只**落在这一档）。
- **T2** = 无立直，但**副露数 ≥2**（手牌 ≤7 ⇒ 牌理上几乎テンパイ圏）**或**副露含**役牌/宝牌**：可判（`obs.melds` + `obs.dora_indicators`），但"威胁程度"没有权威量 ⇒ 阈值是拍的（歧义度中）。
- **T3** = 无 T1/T2，但至少一家「**dama 可疑**」：⛔ **必须**是**冻结且与结果无关**的公开估计量（巡目 ≥10 ∧ 最近 6 张全ツモ切り ∨ 牌河单一花色 ≥70% ∨ 中張牌占 ≥80%）；任何"用本局结果/别家手牌标定"的写法 = 把隐藏信息泄漏进奖励（歧义度最高，只能当**上界估计**）。
- **本轮实测（400 场标定采集 / 学生席 68044 决策行 / 51893 出牌行）**：T1 **10848**（20.90% 出牌行 / 15.94% 决策行）· T2 **5604**（10.80% / 8.24%）· T3 **1893**（3.65% / 2.78%）· 均不属 **33548**（64.65% / 49.30%）；`fold` 付奖行 **673** 行**全在 T1**。
- ⇒ **扩档的代价**：机会集 T1∪T2 = 16452 行、T1∪T2∪T3 = 18345 行（分母变大、**付奖行数不变**）⇒ 降り率从 6.20% 摊薄到 4.09% / 3.67%；**付奖行率/决策行不变**（0.989%）⇒ 单独看"过不过 1%/行 门槛"，扩 T2/T3 **帮不上**（要涨的是**分子**，除非同时把"对至少一家安全"这类更宽的安全口径也算进去）。

## 7. 候选标的的**最终裁定**（2026-10-11 收束；逐条对应 §2 的 A~K · 正文一字未动、⛔ 未重排原表）

- ⛔ **判死**：**A 押し率/降り率**（`fold` 两口径付奖行率 **1.04% / 1.68%**，主判据 Δ=−0.063[−0.396,+0.270] 与 +0.148[−0.267,+0.563] **CI 均含 0** —— 第二口径的付钱路已按名义剂量付满 ⇒ 不是剂量问题）· **E 见逃率**（付奖行 **= 0**：2265 行全选和了）· **E′ `win` 行**（`no_deal` **100% 恒真** + 结果量 ⇒ 行级奖励退化成对结果重复加权）· **B 立直巡目**（付奖行率 **0.79%/行 < 1% 门槛** + 主判据 Δ=+0.0666 CI[−0.0770,+0.2101] 含 0）。
- ✅ **可推**：**D 副露种类**（`pon` n=2 合并 **+6.06pp[+4.51,+7.61]**）· **F ダマ**（行级 `decline_rows_per_game` 合并 **+0.1859[+0.1134,+0.2583]**；⚠ 手级 `dama_rate` 不动 ⇒ **只当判据、不当默听率工具**）· 已在用的 **A 之外的两根**（§2 的 `riichi`/`meld`）。
- ⚠ **降级 / 同族降级**：**G 摸切率**、**J 対子志向**（判别力≈0：摸切 `deal` 17.7% vs 20.4%、対子 **19.7% vs 19.7%**）⇒ 只当**读数/特征**；**H ドラ保持**、**I 染め志向**（与 A 同属"给定状态下选哪个方向"）⇒ **同族降级**，要救须改成**同状态下的对比式优势**（未验证设想）。
- ⏸ **待定**：**C 副露巡目**（与 D 同路线、未跑）· **K 局面依存押し引き**（A 的二阶轴，A 判死 ⇒ 暂缓）· **A′ 鸣牌威胁押し**（付奖行 0.80%/行 < 1% ⇒ 并进 A/K）。
- **族级**：三族里只有**"进攻手段"族**（B/C/D/E/F 里的**动作类型/频率**维度）站住了；**"风险处理"族**（A/K）判死；**"手作り"族**（H/I/J）同族降级。判据与复现细节见同目录 `STYLE-CONTROL-STATUS.md`（⛔ 在数据根、不进仓库）。

## 8. 打点裁定对候选轴的筛选含义（2026-10-11 用户架构级裁定 · 与 `NOTES.md` §6.5 末尾、`STYLE-CONTROL-STATUS.md` §9 同措辞）

- **① 防守有效性另立新文件**：完整口径（行为 / 有效性 / 判决三层 + ΔEV + 功效表 + 判定表）见同目录 **`DEFENSE-EFFECTIVENESS.md`**（⛔ 数据根内，不进仓库；本文件不重复它的内容）。
- **② 裁定（原文意思）**：专家风格模型**可由附加的激活模型按情境选择启用** ⇒ **单线不必全局均衡**；`rank_points` **保留为唯一硬门**，打点 `avg_win_score` 由「越界判据」**降级为风格签名坐标**（只在**结构性强界**时报警）；**打点判据 = 三个坐标 + 一个主尺度**（2026-10-11 两步裁定；⛔ 作废上一批的「单一 −600 点 / incumbent ≈90%，取宽」—— 它不再生效）：**主尺度 = 全有局（每小局，含流局/别家和）× 净得失点**（与 `ΔEV`/`rank_points` 同族，**主判据永远落在它**或闸门的**每场顺位点**上），分档**按坐标**（②③ 是主尺度的分解项）—— **① 机会量**（全有局）守=记录 / 速=**收益需显著** / 攻=记录；**② 机会质量**（**和了局**打点）守=**只记录** / 速=**换算后判（≤5×SE）** / 攻=**严判（CI 下界 ≥ 0）**；**③ 风险**（全有局放铳/失点）守=**主门（ΔEV）** / 速·攻=**伴随（不许显著变差）**。⚠ **打点不是"固定带"的问题，更该先定"分母"**：**进攻线不一定打点不下降**（理由：**点炮概率在变大**）⇒ 打点升降**不能替代**主尺度；两条代价 = ① **功效随基数变化**（`和了局` n ≈ 全有局的 **~20%** ⇒ **SE 放大 √5** ⇒ 同一效应要 **×5 场次** ⇒ "和了局打点"**只当坐标、不当主判据**）、② **有条件基数的选择效应是内生的**（线会改变"赢哪些局" ⇒ 配对比仍成立，但只能解释为"**你赢的那些局值多少钱**"，⛔ 不是"创造了多少价值"）—— ⚠ **待预注册冻结后才用于判决**（基数矩阵见 `DEFENSE-EFFECTIVENESS.md` §5）。
- **③ 对本表候选轴的筛选含义**：**打点不再是一刀切的否决项，而是按坐标分档** —— **主尺度 = 全有局净得失点**（**主判据永远落在它**）；**守线**（押し率/降り率、任何 `no_deal` 伴随的量）在 **② 机会质量（和了局打点）上只记录、不设门**，它用的**主门是 ③ 风险坐标上的 ΔEV/失点轴**（`DEFENSE-EFFECTIVENESS.md` §3、§5；理由是**别家荣和/自摸会机械地压低自家总得点是必要的**）；**速线**（副露率/副露种类/立直巡目）在 ② 上按**换算**判（保守默认 **≤5×SE**，**纯亏才否**）；**攻线**（`win_points`(atk)、未来 `ドラ保持`/`染め`）在 ② 上**严判**（平均打点 **CI 下界 ≥ 0**）。§2 的"伴随质量量"里凡以打点论生死的一律改判为**坐标（签名）**；由此 **`H ドラ保持` / `I 染め志向`（"手作り"族）的价值随之上升**，因为它们本来就是**打法点**的方向：过去 §7/`STYLE-CONTROL-STATUS.md` §4 判它们"同族降级"靠的是"打点代价 + 方向轴推不动"两条，现在**代价那一半不再出局**，只剩"能不能推"（要救仍须**同状态下的对比式优势**）。
- **④ 战略简化**：**"少量可靠风格 + 一个激活模型" > 铺满 QD 网格**（router 不需要稠密网格 ⇒ §5 的 QD 前置不再是必经）。
- **⑤ 候选轴 → 专家 的映射要求（2026-10-11 架构级澄清；⛔ 与 `NOTES.md` §6.5 末尾 / `STYLE-CONTROL-STATUS.md` §10 / `DEFENSE-EFFECTIVENESS.md` §8 同措辞）**：**不再奢望"一次性训练出全能模型"，改用多种风格模型替代**（各含独特意义）⇒ 单模型**不必完全提升**，只需在**自己的激活域（局部分母）D** 上提升；全局账由 **router** 按局面逐个挑专家拼。故一条候选轴**要当专家**，除"能不能推"（§7）外还必须给出**自己的域 D 与覆盖率 `P(D)`**（**未记录**），并按**条件提升 / 覆盖率 / 泄漏 / 域外表现**四项报（**域外表现只记录、⛔ 不计入单模型成绩**）。
