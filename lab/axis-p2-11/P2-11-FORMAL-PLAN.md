   `--rotate-perm`）：
   - `A0 = net:<wl-riichi>`（基线，本轮**新采**：既做基线，也做逐行机械自证的 A 侧）
   - `A1 = net:<wl-meld>`（**复用**上一轮 `raw/p2-11/meld` 的 summary + `_p2-11-work/hands_meld.json`；
     复用前提写成自证：本轮 A0 的 `per_game` 必须与上一轮 `raw/p2-11/riichi` 的 `per_game` **逐位相同**）
   - `H  = net:<A0>!net:<A1>@kind=claim`（**域掩码真跑** —— 上一轮缺的就是它）
3. **场级统计量** = 学生席 `final_scores[学生席]`（含终局余棒分配；⛔ 不用"逐小局 delta 求和"充当场分）。
4. **F1（预注册 §4「正式」，= 主判据）**：Δ = `H − 最好的单臂`（单臂按场级均值选，⛔ 不与"现任"比）。
   两条件缺一不可：
   - (a) 场级配对 Δ 的 **95% CI 下界 > 0**；
   - (b) **机械自证 D 外两臂逐位相同**：① 学生席在该小局**没有任何 D 行**的 ¬D 小局，A0 与 H 的
     每一行**逐字节相同**（不符必须 0）；② 有 D 行的小局，**第一处差异必须落在学生席的一条 D 行上**。
     ② 失败 ⇒ 判「实现没做到同到可辨状态再分歧」，本轮**作废**（预注册 §6）。
5. **F2（任务点名的"D 上样本外路由增益"读法，= 副判据）**：只在 **D 手**（学生席在该小局出现过 D 行）
   上、只用**公开观测**的 cell（该小局第一条 D 行的 `draw_band×riichi_band[×menzen][×D 行数档]`），
   **交叉拟合奇/偶场互评**（奇数场拟合 cell→是否路由、偶数场评估，两方向合并）：样本外增益 + 配对
   Δ/SE/95%CI。参照系 = 固定掩码（`H` 全 D 路由，无需拟合）。⚠ 它**不能**替代 F1：cell 是在同一批
   真跑结果上事后切的，只读"域内有没有可路由结构"。
6. **对照**：¬D 手上的同式增益（应恒 0）· `ρ(神谕增益, A0 该手得分)` 与 `ρ(真跑增益, A0 该手得分)`
   （门槛 **|ρ| < 0.25**）· 剔最差 5/10/20/30/50%（按 A0 该手得分）后的剩余增益。

   Δ 读不出来）；⚠ 单套牌山 ⇒ 一切读数**条件于该套牌山（52870101）**。
