## 2 读数（口径与候选①**逐字相同**，`P2-11-FORMAL-PLAN.md` §3-§6）
1. **配对自证**：seed / 学生席 / 对手桌逐场一致 + 本轮 A0 的 `per_game` 与 `raw/p2-11b/base` **逐位相同**。
2. **覆盖率**（Python 侧，与候选①同一把尺子：分母 = A0 学生席**全部**决策行）。
3. **改判率**（C++ 侧，`trainer v4net A1` 只前向 A0 的 D 行）：`argmax_B != A0.chosen_index` 的占比；
   并要求 **同状态自证** `argmax_B == H 实际打出`（匹配行数 > 0，不符 **必须 0**）。
   ⚠ 该自证同时是"**D 集合没被 Python 判宽**"的**证伪测试**：判宽 ⇒ 那些行 H 与 A0 相同 ⇒ 不符数 > 0。
4. **F1(a)（主判据）**：Δ = `H − 最好的单臂`（单臂 = A0/A1 场级均值较大者），**场级配对** Δ/SE/95%CI，
   **判据 = CI 下界 > 0**。
5. **F1(b)（机械自证）**：`first_diff_hand_of_game` 由逐行字节比对给出；**¬D 小局（前缀内）逐字节相同**（不符 0）
   *且* **第一处差异都落在学生席的 D 行上**（例外 0）。② 失败 ⇒ 「实现没做到同到可辨状态再分歧」⇒ 作废。
6. **F2（副判据）**：只在 **D 手**上、只用公开观测 cell，**交叉拟合奇/偶场互评**（两方向合并），
   单位 = ①**边界小局**（第一次改判那一手）②**场**；至少两种分层（`c1=draw_band×riichi_band`、
   `c2=+menzen`）；第三种 `c3=+该手 D 行数档`。
7. **对照**：**前缀（¬D）手**的同式增益 **必须恒 0**。
8. **ρ**：`ρ(神谕增益, A0 该手得分)` 与 `ρ(真跑增益, A0 该手得分)`（**门槛 |ρ|<0.25**）+
   剔最差 5/10/20/30/50%。
9. **单域判过** = F1(a) **且** F1(b)。**整族判据（预注册 §6）** = **所有**候选域皆不过 ⇒ **封存整族**。
10. ⚠ 一切读数**条件于该套牌山（52870101）**。

## 3 成本与止损
- 实测口径：A0 采集 ≈283 s、H 采集 ≈500 s、抽取 ≈115 s、逐行自证 ≈180 s、域内前向 ≈4.5 ms/行。
  预估 5 域 ≈ **95 min**；**硬上限 150 min**（超限则剩余域写「本轮未测 + 原因」，⛔ 不降测量质量去凑数）。
- ⚠ **本机实测比上一轮慢 ~1.9×**（A0 采集 533.5 s vs 上一轮 283.4 s，同一命令同一权重）⇒ 本文件在
  **任何域读数之前**补两条**跑前写死**的口径（⛔ 跑后不许改）：
  - **改判率抽样上限**：某域 D 行数 > **20,000** 时，`dforward` 只前向**等距抽样**的 20,000 行
    （`drows[::stride][:20000]`，确定性、无随机源），报告里记 `n_D_dforward` 与抽样说明。
    ⚠ 改判率是**描述量**（不进 F1/F2/ρ 判据）⇒ 抽样不影响"过/不过"；覆盖率仍是**全量精确计数**。
  - **逐行自证流式化**：`domdiff` 边读边比、**遇到该场第一处分岔即停**（下游行不再读）；
    因此 `D_rows_a_total` 只覆盖"读到的那部分小局"，判据改成"**已读部分**的 D 行数 == rows 集合里
    对应 (game,hand) 的 D 行数"（键错位在**第 0 手**就会炸，仍然有效）。
  - **跑序**（先便宜的，且先用最便宜的域把整条读数链验通）：`claim_t12`（试点）→ `turn` → `oppriichi`
    → `draw12p` → `draw0-5`。
- 一次只跑一个重负载；`OMP/MKL_NUM_THREADS=6`；每域跑完**立刻落盘一行**（`_p2-11c-domains.jsonl` +
  `_p2-11c-domains.md`）；⛔ 逐手轨迹读完即删（残留 0）；⛔ 不动他人产物。
