> ⛔ 不跑训练、不跑闸门；⛔ 仓库零改动；低压力：`--workers 6` · `OMP/MKL ≤6` · 一次一个重负载 · 逐手轨迹读完即删。

1. **域 D = `obs.kind == "claim"`**（鸣牌询问行）＝ 预注册候选①；覆盖率 **21.18%**（精确 36,215/170,994）。选它：`kind` 是自家信息集字段（零隐藏信息）、**零阈值精确可判**、是"域条件化单网"最自然的切法、≥1%/行 门槛的 21×。**次域 D2** = 别家已立直 ∧ 自家出牌行（15.305%）**只作并列描述**，不进主判据。
2. **臂**：`A0 = wl-riichi`（`ROUTING-CEILING-COMMON` §6.1 里**唯一显著强于现任**的臂，t=3.709）· `A1 = wl-meld`（行为差最大、逐小局 ρ=0.250 最低）。纯 `net:`（无 `@`/`#`）＝ 逐行 argmax；同 `seed_base=52870101`（与实验 A 同族 ⇒ T0/T2 可作**逐位复现对照**）× 1000 场 × 同一三席风格桌（def7/win2/atk3）。
3. **受控干预臂 `A0[D←A1]`** = D 内取 `A1` 在**同一 `obs`** 上的 argmax，**D 外逐位取 `A0`** —— 干预发生在**同一张网、同一状态**上，D 外逐位相同是**定义**而不是巧合（= §1 的"同到可辨状态再分歧"）。
4. **T0 机械自证（前置，失败即作废）**：`v4net` 前向复算 `A0` 的逐行 argmax，必须与实际 `chosen_index` **逐行 100% 相同**；据此重建 `A0[D←A1]` 的逐行动作，**D 外 0 处不符**；并给 D 内"改判行"的比例与合法性（两臂看同一 `legal` ⇒ 落位必然合法）。
5. **T2 结构读数**：D 上**背离率** `P(argmax_A0 ≠ argmax_A1 | D)`、近平局率（policy top1−top2 margin ≤ 0.5）、D 触及的小局覆盖率；D2 同式并列。
6. **T1 正式判据 —— 事前声明：本仓当前工具下不可识别。** `trainer` 只认 `net:<w>[@α][#T] / pass / first / random / teacher`（`trainer/src/policies.hpp:policyFactoryByName`），**没有逐状态条件切换** ⇒ `A0[D←A1]` 落不成策略串、走不完一整场，它的"得分"不存在。⛔ **不伪造数**：T1 记"不可识别 + 需要什么能力"，**不等于判过**。
7. **T1-proxy（可识别的那一半；⚠ 上界代理、不是正式判据）**：用两条**可玩**臂的逐小局配对账，**只在 D 上**做交叉拟合（奇数场定策略 / 偶数场评估，两方向合并；只用公开观测）的状态限制神谕 ⇒ 样本外增益 + 配对 Δ/SE/95%CI + `ρ(增益, A0 自身该小局得分)`（预注册要求 `|ρ| < 0.25`）+ 剔最差 X% 后剩余增益。⚠ 它**不能**把增益归因到 D 决策（两臂在 D 外也不同）⇒ 只读"域上有没有可路由结构"。
8. **止损/判读**：T0 失败 ⇒ 该轮作废（"实现没做到同到可辨状态再分歧"）；T2 背离率 ≈ 0 ⇒ 判「**域选错**」；T2 背离率不低而 T1-proxy CI 含 0 或 `|ρ| ≥ 0.25` ⇒ 判「**不可识别（实现缺口）**」并给出补能力的最小方案与预算。⚠ 单套牌山 ⇒ 一切读数**条件于该套牌山**。
9. **成本（硬上限：墙钟 120 min）**：采集 2 臂 ×1000 场 @workers=6 ≈ 20 min · 抽取 ≈ 4 min · `v4net` 前向（主臂全行 + 对手网全行）≈ 17 min · 统计 ≈ 3 min ⇒ **≈ 45 min**。逐手轨迹读完即删（残留 0）；⛔ 不碰他人产物。
