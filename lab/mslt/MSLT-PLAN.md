## 1 自变量 / 臂 / 数据
- **自变量** = **段数 × 每段步数**（多段长训练），**唯一变化量**。
  ⛔ **它不是"换机制"**：无新架构 / 无新损失 / 无新数据 / 无新特征；阶段划分、`base_lrs`、
  `accum`、`batch`、`lr`、`grad_clip`、KL 阈值**全部逐字沿用 A 臂 recipe**（下表）。
- **⭐ 为什么 BL-03 的「新臂先过 ceiling」在本例不适用**：ceiling 闸门筛的是**"想法 / 域"** ——
  它要拿**两个已存在的网**在**新牌山**上配对，判"这个方向值不值得投 4 代训练"。
  本例的候选网**只在训练跑完的那一刻才存在**（它的全部内容就是"多跑了几段"），
  **闸门在跑前无从收取候选权重** ⇒ 用它当跑前前置是**范畴错误**（会变成"用 A 网冒充候选"）。
- **⇒ 替代的便宜前置（跑前，零训练，≤5 min；全部实测后才开训）**：
  1. **recipe 指纹核对**：§1 表逐键 == A 臂训练命令行（`p301_run.py:211-219`）；
  2. **`--init` == 数据生成策略**：从 raw 里逐行统计 `policy` 直方图（§0 那条 ⭐）；
  3. **分片数据完好**：`train_decisions + val_decisions` == 逐行独立计数 ∧ `meta.student` 串 == 策略串；
  4. **闸门预演**：`--init defrep-g10` 那一段的 KL 必须 ≈0（这正是 §2 判据 1 要贴的原始输出）。
- **臂**：
  | 名称 | 定义 |
  | --- | --- |
  | **候选** | `defrep-g10` 在**冻结紧凑集**上 **3 段 × 150 步 = 450 步**，段间用 `--save-optimizer` / `--resume-optimizer` 串联 |
  | **基准（现任）** | `v4-expert-defrep-g10`（= 训练起点网 = 数据生成策略） |
  | **并列基准（起点网本身）** | 同上 ⇒ 这就是"**多训有没有动**"的直接读数 |
  | **对照（口径已动）** | `v4-wl-p301-B-g06`（+2.5447；由包装器放行闸门训出）—— **只作对照，不当基准** |
- **数据**：`raw\v4-wl-p301-A-g01`（A 臂自己的 12,000 场，**原样保留**）。取**子集**建**一个冻结紧凑集**：
  **A 臂确定性排列 seed=52921001 的 shard 0 = 1,000 场**（已逐场比对 == 既有 `ov-A-s00` 的 1,000 场，
  `SET IDENTICAL = True`）。**牌山族**：本次**不采新牌山**，用闸门族 `53060001/53060002`（与 P3-PKG 同一族，
  目的就是**可比**）。
- **牌山族判据（事先写死）**：**2 族 × 6,000 场 = 12,000 场/臂**。⚠ 与第七十一轮判据「3 族 × 4,000 优于
  1 族 × 12,000」的关系：本次**沿用 P3-PKG 同一族**是刻意的 —— 只有同族才**能与 +2.5447 直接对照**；
  因此**族间散布不作判决依据**，判决**只对本族**成立（⛔ 不跨族外推），并把"族间不自洽"记为残留风险。

## 2 硬判据（逐条贴原始输出）
1. **合规性**：3 段的闸门输出行全部在场；**续训没有触发** PPO 口径闸门；⛔ 全程**无包装器**、**无"口径已动"标注**。
2. ⭐ **多段等价性抽验**：同一紧凑集上跑一次「**一口气 N 步**」与「**N₁ 步 + 存档 + 续跑 (N−N₁) 步**」，
   判据 = `net.bin` sha256 相同 ∧ 逐 step 日志逐字相同 ∧ `perm_sha256` 相同；
   **负向**：把存档里的动量清零 ⇒ 必须**不同**（只有"相等"是假绿）。
3. **训练收敛读数**（如实）：每段 loss / KL / `|g|` / top1 轨迹摘要 + 相对起点网的变化；
   ⚠ KL 早停**若触发照实报触发点**，⛔ 不许改口径把它关掉（确需关 ⇒ 记 §7 偏离）。
4. **闸门判决**：`tools/ceiling-gate.py`（制度化的**便宜**闸门口径）跑**候选 vs 现任**，
   并另按 P3-PKG 的正式闸门口径跑 **12,000 场/臂**，落 `verdict.json`，贴
   主口径 Δ/SE/t/CI · Bonferroni CI · 逐族 Δ 与 spread/半宽 · 实际 MDE · 每条护栏 `tol`/MDE/`usable_as_veto` · 安慰剂 · ρ。
5. **判决**：按下面四条**全部**成立才判"过"：
   ① 95% CI **排除 0 且为正** ∧ ② 护栏（**仅** `usable_as_veto=true` 的）不破 ∧
   ③ Bonferroni CI 也排除 0 ∧ ④ **各族逐族同号** ∧ ⑤ 实际 MDE 落在预测附近（±15%）。
   否则：CI 含 0 ⇒ **测不出**；CI 显著为负或护栏被破 ⇒ **不过**。
6. **回归**：`python selfcheck.py` 跑前跑后各一次，报**条数与失败数**。
- **主口径** `rank_points`；**并列** `score`；**护栏** `wins` / `deals` / `score`。
  ⚠ **基线 MDE（N=12,000）**：`rank_points ≈ 0.97` · `score ≈ 400 点` · `wins ≈ 0.030` · `deals ≈ 0.025`
  ⇒ **容忍带/MDE 比值**：`rank_points` — · `score:150` = **0.37（<1 ⇒ 不得作为否决依据）** ·
  `wins:0.05` = 1.67（可作否决）· `deals:0.05` = 2.0（可作否决）。⛔ 比值 <1 的护栏**只报不判**。

## 3 两种结果的解释（**预先写死**）
- **有增益（CI 排除 0 且为正、逐族同号）** ⇒ **多段长训练合规地把网推强了**。
  量级预期：`+0.6 ~ +1.5` 顺位点/场/席（= 单轮效应量级，已越过 MDE 0.97 才可能显著）。
- **无增益（CI 含 0）** ⇒ ⭐ **`wl-p301-B-g06` 的 +2.5447 就是"口径已动"造成的假象**：
  B 第 2–6 轮用包装器把闸门放行（`logp_old` 来自**上一个**策略、而 `--init` 是**上上轮**的导出），
  PPO 的重要性比被系统性带偏 ⇒ 训出的是"**偏离合法 PPO 目标的方向**"，其读数**不可复现于合规路径**。
  ⚠ 这一条**本身就是重要结论**，并**正好解释** P3-PKG §2.3 的跨族不自洽（同对比两族差 ≈2.2 点）。
- ⚠ **分辨率声明**：n=12,000 的 MDE ≈ **0.97**，而单轮效应量级 ~0.6 ⇒ **"测不出" ≠ "变差"**。
  本测**没有**能力分辨 0.6 点这一档；判"测不出"时**只能说这一档分不开**，⛔ 不得外推为"无增益"。
